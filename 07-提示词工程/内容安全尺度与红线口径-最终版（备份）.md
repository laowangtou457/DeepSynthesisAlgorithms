### 0.2 三条效力规则

1. **从严原则**：多份文件对同一事项要求不一致时，执行**最严的一档**。平台规则严于法规时，按平台规则执行（因为它是播出前置条件）。
2. **移动靶原则**：L4 平台规则常态化更新（抖音该指引 2026 年 5 月首调、7 月 13 日迭代，把审核范围从正片扩大到剧名、简介、封面、改编 IP 原著名）；L3 国标按版本号锁定。**使用前必须复核**（见附录 C）。
3. **未核实不写原则**：任何未在官方文档中逐字核实的具体禁用词，不写入本文件。本文件所有具体词条均标注出处。

### 0.4 一票否决项（整剧级）

**这是本项目最高优先级的红线。** 依据抖音漫剧规范，审核已从「单集点查」升级为「**全剧综合评估**」：

> 全剧的立意导向，包括**主线剧情、核心情节、人物塑造、结局走向**，不可脱离正向叙事。**局部合规不能对冲整体跑偏——整剧直接不过、作废。**

判据（四项须同时成立）：
- [ ] 主线剧情：有正向价值落点（成长、救赎、担当、正义伸张），不是纯粹的复仇爽感输出
- [ ] 核心情节：关键转折服务于人物成长，不是为刺激而刺激
- [ ] 人物塑造：主角有可理解的动因，反派有被否定的结局
- [ ] 结局走向：与正向叙事一致，**不允许「以暴制暴获胜」「恶人得逞」「价值虚无」式收尾**

### 1.5 分级处置口径

词库每条必须带处置等级，分三档：

| 等级 | 标识 | 含义 | 处理动作 |
|---|---|---|---|
| **禁止** | `block` | 命中即不可用，无解释空间 | 删除并重写该句／该镜 |
| **改写** | `rewrite` | 意思可保留，表达必须换 | 按 §2 的改写示例替换 |
| **人工判** | `review` | 依赖上下文，机器判不了 | 转人工审核岗判定 |

> **重要**：`review` 档**不得自动放行**，必须有人工签核记录。备案评估会查审核台账。

### 1.6 词库建设与维护（工程任务）

**数据结构（每条记录）**：

```
term           词条
category       A.1 ~ A.5
sub_risk       组内具体风险名（如「宣扬暴力/淫秽色情」）
severity       block | rewrite | review
action         处置动作说明
replacement    推荐改写（rewrite 档必填）
source         出处（法源或平台规则条目）
updated_at     更新时间
```

**工程要求**：

1. **词库不入代码**，入配置文件或数据库，支持**热更新**（不重启服务即可生效）。
2. **更新机制**：至少每周一次；重大社会事件、平台规则更新后 **3 个工作日内**即时增补。
3. **台账留痕**：每次更新记录时间、增删条目数、变更原因、操作人——**这是备案评估的必查项**。
4. **多模态覆盖**：文本词库之外，图片／视频类内容另设画面风险项清单（对应 §2 的题材边界条目）。
5. **与测试题库联动**：词库覆盖 A.1+A.2 的 17 类，测试题库须覆盖**全部 31 类**（见 §3.5）。

## 2. 漫剧题材边界

> **本节是编剧与分镜设计的直接操作依据。** 每类题材按三档给出：**可写**（正常表现）／**克制**（可保留但必须做减法）／**禁止**（不得出现）。
> 判定基准来自抖音集团《动画微短剧（漫剧）内容创作建议》六大创作红线 + 广电总局专项治理重点。

### 2.0 总原则

1. **情节必须服务于剧情的合理逻辑**，适用于人物的合理设定与动因。**不是「能不能拍」，而是「拍了有没有必要」。**
2. **观感优先于内容**：同样是「有人死亡」，远景倒地可过，伤口特写不过。**镜头语言决定合规与否**，不是情节本身。
3. **不渲染、不美化、不教学**：暴力可以存在，但不得渲染爽感；犯罪可以出现，但不得提供可模仿的方法。
4. **有因有果**：暴力／犯罪必须有明确的否定性结局，不得以「胜利」收尾。

### 2.1 暴力

> **本项目核心风险面**（《蛊》含刀战、江湖斗殴情节）。平台明确禁止「过度呈现血腥暴力」「宣扬暴力仇恨」。

#### 可写

| 内容 | 说明 |
|---|---|
| 对峙、蓄势、气势压迫 | 眼神、脚步、握兵器的手部特写 |
| 格挡、闪避、招架 | 兵器交击（有火花、无血） |
| 身形腾挪、衣袂翻飞、走位 | 动作设计的主要表现空间 |
| 击倒、制服、擒拿、卸力 | 不展示伤口与变形 |
| 兵器脱手、踉跄、跪地喘息 | 用姿态表达挫败，不用伤口表达 |
| 战斗结果的远景／剪影 | 剪影、雨幕、逆光是最安全的暴力表达方式 |
| 战斗后的狼藉现场（倒地的兵器、翻倒的桌椅） | 以环境暗示，不拍人 |

#### 克制（可保留但必须做减法）

| 内容 | 必须遵守的限制 |
|---|---|
| 血迹 | **仅限**「衣襟染血」「嘴角渗血」这类**非特写**表现；**不得出现血液飞溅轨迹、血泊** |
| 伤口 | **不得特写开放创面**；不得展示伤口细节、深度、组织 |
| 疼痛反应 | 可以皱眉、闷哼、咬牙；**不可长时间凝视惨叫特写** |
| 死亡 | **可表现倒地静止**；不可表现濒死挣扎、抽搐特写 |
| 群殴 | 必须用远景／中景带过，**不得给出单个击打点的特写** |

#### 禁止

| 禁止项 | 说明 |
|---|---|
| 刀刃入肉、穿透身体的特写 | 命门级条目 |
| 血液喷溅、血泊、血溅到镜头 | 命门级条目 |
| 断肢、割喉、开膛、挖眼、剖腹、剥皮 | 命门级条目 |
| 虐杀、折磨过程的展示 | 平台明令「规避展示／描述恶心行径」 |
| **以暴制暴的爽感渲染** | 广电总局专项治理重点，明确点名 |
| **极端复仇** | 广电总局专项治理重点，明确点名 |
| 详细、可模仿的伤害方法 | 教唆犯罪风险，A.1 第⑧类 |
| 对死亡过程的长时间凝视与美化 | 价值观问题 |
| 对儿童、老人、女性施暴的针对性描写 | 平台明令加强保护敏感群体 |

#### 改写示例（可复制的操作口径）

| 原始写法（不过） | 合规改写（可过） |
|---|---|
| 刀锋没入胸膛，鲜血喷涌而出 | 刀锋逼近的**剪影**，画面切至对手瞳孔骤缩，随后是雨中倒地的远景 |
| 特写他腹部深长的伤口，血顺着手臂滴落 | 他按住腰侧，指缝渗出一线暗红，撑墙起身 |
| 乱刀砍杀，血肉模糊 | 镜头拉开至远景，只见刀光起落与雨幕，人影在剪影中交错 |
| 他一刀割开对方喉咙 | 刀光一闪，对手捂住咽喉踉跄后退，画面切至旁人的惊恐反应 |
| 为了复仇，一个个杀掉仇家（爽感剪辑） | 复仇念头把他推向毁灭边缘，他最终选择收刀，将证据交给官府 |

> **操作要点**：**把「结果」换成「反应」，把「伤口」换成「姿态」，把「特写」换成「远景／剪影」。** 三句话可以解决绝大多数暴力镜头的合规问题。

### 2.2 悬疑

> 平台明确禁止「过度血腥、恐怖、惊悚、恶心」，禁止「过度呈现／宣扬迷信糟粕」「法术玄学」。

#### 可写

| 内容 | 说明 |
|---|---|
| 悬念铺设、伏笔、反转 | 悬疑的核心竞争力，完全安全 |
| 推理过程、心理博弈、审讯对峙 | 台词与表演驱动 |
| 气氛营造：雨夜、空旷空间、阴影、风、烛火 | **用光和声音造恐怖，不用血肉造恐怖** |
| 线索特写：信物、脚印、烛泪、断指节（非人的） | 物件驱动 |
| 危险逼近的主观视角、脚步声由远及近 | 悬念而非惊吓 |

#### 克制

| 内容 | 必须遵守的限制 |
|---|---|
| 尸体 | 可**远景／盖布／局部**（手、脚、衣角）；**不可正面特写** |
| 命案现场 | 可暗示（翻倒的器物、地上的血迹轮廓），**不可拍创面与器官** |
| 惊悚音效 | 可用，但**避免高频刺耳的长时段刺激** |
| 诡异画面 | 可**暗示**（镜中的影、门缝里的注视），**不可直给鬼怪形体** |
| 精神异常／幻觉 | 可表现，须在结局给出理性解释或否定性处理 |

#### 禁止

| 禁止项 | 说明 |
|---|---|
| 过度恐怖、惊悚、恶心场景 | 平台 6 大红线「画风观感不适」 |
| 详细犯罪手法（可模仿） | 教唆犯罪风险 |
| 血腥命案现场特写 | 命门级条目 |
| 灵异／迷信作为**真实有效的力量**被肯定 | 见 §2.5 |
| 残忍的作案过程展示 | 「规避呈现恶劣观感画面」 |
| 以「凶手获胜」收尾 | 价值观一票否决 |

#### 改写示例

| 原始写法（不过） | 合规改写（可过） |
|---|---|
| 尸体被剖开，内脏暴露，特写 | 白布覆盖的轮廓，一只手垂在床边，指尖沾着干涸的血 |
| 凶手详细演示如何制造不在场证明 | 凶手意味深长的一句「时间会替我作证」，细节留白 |
| 女鬼从镜子里爬出来，面目狰狞 | 镜面莫名泛起水痕，映出的影子多了一个，转头却空无一人 |

### 2.3 情感 / 婚恋

> 平台明确禁止「过度呈现／宣扬错误伦理观」「过度呈现／宣扬错误金钱观」；广电总局专项治理点名「**畸形婚恋观**」「歪曲主流婚恋观」。**封面**另禁止「展现非正当婚恋／情感关系人物亲密互动」。

#### 可写

| 内容 | 说明 |
|---|---|
| 正常恋爱的相识、试探、确定关系 | 情感主线 |
| 亲情、友情、师徒情、同门之义 | 武侠题材主力 |
| 分别、重逢、守护、牺牲 | 正向情感落点 |
| 情感冲突（误会、立场对立） | 必须有合理动因 |

#### 克制

| 内容 | 必须遵守的限制 |
|---|---|
| 亲密戏 | **仅限牵手、对视、拥抱**；不得有性暗示动作或镜头语言 |
| 情感纠葛 | 可写，但**不得美化不忠、不得把破坏他人关系写成浪漫** |
| 婚恋冲突 | 冲突必须有解决与成长，孤立停留在「虐」本身 |

#### 禁止

| 禁止项 | 说明 |
|---|---|
| **畸形婚恋关系** | 广电总局专项治理重点，明确点名 |
| 美化出轨、婚外情、多角关系 | 平台明令「出轨等不良恋观」 |
| 拜金婚恋观（「嫁入豪门改变命运」式宣扬） | 平台明令「拜金炫富」 |
| 性暗示、性挑逗、易使人产生性联想的画面 | 见 §2.10 |
| 性暴力情节 | 平台明令禁止 |
| 未成年的恋爱／暧昧暗示 | **绝对红线**，见 §2.6 |

### 2.4 复仇

> **这是短剧最高频的踩线题材。** 广电总局专项治理点名「**以暴制暴、极端复仇**」；抖音禁止「宣扬暴力仇恨」。

#### 可写

| 内容 | 说明 |
|---|---|
| 复仇的**动机**建立（不公、失去、冤屈） | 情绪成立的必要条件 |
| 复仇过程中的**挣扎与代价** | 人物弧光所在 |
| **放下复仇**、转向正当途径（官府、律法、证据） | 唯一安全的收尾方向 |
| 复仇者最终被自己的仇恨吞噬并醒悟 | 否定性处理 |

#### 禁止

| 禁止项 | 说明 |
|---|---|
| 私刑复仇的爽感渲染（快意恩仇式剪辑） | 命门级条目 |
| 以暴制暴获胜的结局 | 价值观一票否决 |
| 复仇对象被残忍折磨的展示 | 「规避展示恶心行径」 |
| 把复仇当作正面的、无需代价的解决方案 | 平台明令「禁止宣扬暴力仇恨」 |

#### 改写示例

| 原始写法（不过） | 合规改写（可过） |
|---|---|
| 手刃仇家满门，大快人心 | 刀已架在仇人颈上，他却收刀入鞘——「杀了你，我与他有何分别」 |
| 一路杀上去，血洗宗门 | 一路搜证，将罪证呈上公堂，宗门在律法面前瓦解 |
| 复仇成功的痛快结局 | 复仇完成后他并未解脱，反而是空茫；最终选择重建而非继续 |

### 2.5 封建迷信与玄学（★ 本项目《蛊》题材核心约束）

> **这是本项目最关键的一节。** 平台明确：**「作品的核心应该是破除迷信，提倡科学精神，禁止传播迷信思想和迷信观念」**，并明确禁止「过度呈现／宣扬迷信糟粕」「过度呈现／宣扬法术玄学」。
> 《蛊》题材（蛊术、巫祝、秘法）**天然落在这个红区**，必须给出明确处理规则。

#### 处理总原则（三条）

1. **不得作为真实有效的超自然力量被肯定**：蛊术不得被呈现为「确实有超自然效力」的存在。
2. **必须落在「民俗文化」或「人为骗局」两端**：要么作为地域民俗／文化符号呈现，要么最终被揭示为人为操控（下毒、暗示、心理操控）。
3. **结局必须否定迷信**：作品的落点应是「破除迷信、回归理性」，或至少让迷信手段承担明确的否定性代价。

#### 可写

| 内容 | 说明 |
|---|---|
| 蛊术作为**民俗文化元素**（传说、禁忌、仪式感） | 文化质感的来源 |
| 蛊术作为**反派的迷信手段** | 反派信它，主角用理性破解 |
| 蛊术作为**心理操控与药物作用**的伪装 | 最终揭示「蛊」的真相是毒物／暗示 |
| 村民对蛊术的恐惧与盲信 | 用于刻画迷信之害 |
| 破除蛊术骗局的过程 | **最安全的叙事方向** |

#### 克制

| 内容 | 必须遵守的限制 |
|---|---|
| 仪式场面 | 可拍，但不得给出**可模仿的完整操作步骤** |
| 蛊虫形象 | 可暗示、可剪影；**不得恶心特写**（见 §2.9） |
| 超自然暗示 | 可留悬念，但**结局须给出理性解释** |
| 「玄学能力」 | 不得作为解决问题的手段；不得有「念咒即成」式呈现 |

#### 禁止

| 禁止项 | 说明 |
|---|---|
| 蛊术／法术被呈现为**灵验的真实力量** | 命门级条目 |
| 宣扬迷信糟粕、法术玄学 | 平台明令 |
| 渲染「某地某族都会下蛊」式地域／民族影射 | 触碰 A.2 歧视红线 |
| 提供可模仿的施术方法、咒语、配方 | 教唆风险 |
| 以「玄学解决问题」作为结局 | 违背破除迷信导向 |
| 把迷信作为**正面**的、值得信仰的存在 | 价值观一票否决 |

#### 改写示例

| 原始写法（不过） | 合规改写（可过） |
|---|---|
| 他念动咒语，蛊虫应声钻入敌人体内，敌人当场暴毙 | 敌人饮下那碗药汤后倒下；「蛊」的名头，不过是让人不敢追问的幌子 |
| 蛊术传承千年，威力无边 | 蛊术是这片山地的禁忌传说，村人谈之色变，却无人见过真正的「蛊」 |
| 主角靠蛊术一路无敌 | 主角靠的是对毒理的钻研与对人心的洞察，蛊术只是他借用的名号 |

> **给编剧的一句话结论**：**蛊可以是「名」，不可以是「力」。** 让蛊术成为叙事中的谜面，让理性成为谜底。

### 2.6 未成年人

> 平台**单列一条红线**：禁止呈现未成年负面内容，以「保护未成年人身心健康、维护敏感群体合法权益、防范歧视与伤害」为核心创作原则。
> 广电总局专项治理明确：以未成年人为主角或受众的作品，须符合《未成年人节目管理规定》的内容标准和适龄提示要求。

#### 绝对禁止（无例外）

| 禁止项 |
|---|
| 涉未成年的恋爱、暧昧、性暗示 |
| 涉未成年的暴力、虐待、恐怖内容 |
| 涉未成年的有害行为植入 |
| 可能引发未成年人模仿不安全行为的情节 |
| 丑闻劣迹人员的形象、声音用于制作素材 |

#### 注意事项

1. **年龄设定必须明确**：主角若为少年，须与「成年」有清晰界限；情感线不得落在未成年角色身上。
2. **儿童标签内容从严**：若打「儿童动画」「萌系画风」等标签，须落实未成年人专员审核与适龄提示。
3. **不鼓励未成年人脱离监护人**的冒险行为。

### 2.7 金钱观 / 伦理观

| 档位 | 条目 |
|---|---|
| **禁止** | 宣扬拜金主义、炫富、奢靡之风；把财富作为唯一价值标准；「有钱即正义」式叙事 |
| **禁止** | 过度呈现／宣扬错误伦理观（如「为达目的不择手段」被肯定） |
| **可写** | 财富的代价、因财失义的反面教材、清贫中的坚守 |
| **克制** | 奢华场面的呈现须服务于批判而非展示 |

### 2.8 政治 / 民族 / 宗教

> 平台第 6 条红线：禁止危害国家统一、主权和领土完整与国家安全，泄露国家秘密，损害国家荣誉，煽动民族仇恨，破坏民族团结，宣扬历史虚无主义、歪曲革命历史与英雄形象。

| 档位 | 条目 |
|---|---|
| **绝对禁止** | 上述全部情形（A.1 第②③⑤类 + A.2 第①②类） |
| **绝对禁止** | 影射现实民族、宗教、地域群体的负面设定 |
| **注意** | 架空设定中的「门派／族裔／信仰」须与现实群体有**可辨识的距离**，不得使用现实民族、宗教称谓作为反派标签 |
| **注意** | 宗教仪式、宗教符号不得被用作反面元素的标签 |

### 2.9 观感不适（血腥 / 恐怖 / 惊悚 / 恶心）

> 平台第 4 条红线：**禁止过度呈现血腥暴力、规避展示／描述恶心行径、规避呈现恶劣观感画面**。目的是避免给受众造成强烈生理／心理不适，避免诱发模仿行为。

| 档位 | 条目 |
|---|---|
| **禁止** | 器官、内脏、血肉模糊、蛆虫、腐尸特写 |
| **禁止** | 残忍、恶心行径的展示或描述 |
| **禁止** | 长时间的高压惊悚刺激 |
| **克制** | 阴暗／压迫感可用光影与声音营造，**不用生理不适营造** |
| **克制** | 血的表现限于「非特写的淡痕」 |

### 2.10 低俗色情

> 平台第 5 条红线：严格避免以性为卖点、突破公序良俗、侵害未成年人、违背主流价值观的视听语言与情节画面。

| 档位 | 条目 |
|---|---|
| **禁止** | 以性暗示、性挑逗为卖点的画面或情节 |
| **禁止** | 性暴力情节 |
| **禁止** | 大面积露胸露背的服装（封面明确禁用） |
| **禁止** | 未成年人相关的一切性化内容（**最高优先级红线**） |
| **克制** | 亲密戏限于牵手、对视、拥抱 |

### 2.11 题材边界速查表

| 题材 | 可用度 | 核心红线一句话 |
|---|---|---|
| 暴力 | **谨慎可用** | 用剪影与反应代替伤口与特写 |
| 悬疑 | **安全** | 用光与声造恐怖，不用血肉 |
| 情感 | **安全** | 不得美化出轨与畸形关系 |
| 复仇 | **高风险** | 必须收在「放下／正当途径」上 |
| 蛊术玄学 | **高风险（本项目核心）** | 蛊是「名」不是「力」，结局须破迷信 |
| 未成年人 | **极度敏感** | 不涉恋爱、暴力、恐怖 |
| 政治民族宗教 | **绝对禁区** | 不碰、不影射 |
| 血腥恐怖恶心 | **受限** | 观感优先，不造成生理不适 |
| 色情低俗 | **绝对禁区** | 不以性为卖点 |

### 3.1 提示词写法规避（与 `07-提示词工程` 对接）

提示词工程阶段的**内容安全自检清单**。写入提示词前逐条过一遍：

| # | 检查项 | 判定 | 处置 |
|---|---|---|---|
| 1 | 提示词描述的画面，是否含**禁止档**条目（§2 各类） | 命中即改 | 按改写示例替换 |
| 2 | 是否含「伤口／喷血／断肢／创面」类描述词 | 命中即改 | 换为剪影、反应、远景 |
| 3 | 是否含「以暴制暴／快意恩仇／血洗」类爽感表述 | 命中即改 | 改为挣扎、代价、正当途径 |
| 4 | 是否含「念咒即成／法术生效／蛊虫入体」类**灵验**表述 | 命中即改 | 改为民俗名号／人为骗局 |
| 5 | 是否含「畜生／垃圾」等人身侮辱词 | 命中即删 | 换中性表达 |
| 6 | 是否有**扇耳光／下跪磕头**类动作 | 命中即删 | 换为对峙、后退、握拳 |
| 7 | 是否有大面积露胸露背的服装描述 | 命中即改 | 换常规服装 |
| 8 | 是否含未成年人相关的恋爱／暴力／恐怖 | 命中即删 | **绝对红线，无改写空间** |
| 9 | 是否有「杀疯了／爽到飞起／爆款／热播／强推」类词 | 命中即删 | 剧名／简介禁用语 |
| 10 | 是否含暴力结果的**长时间特写**凝视 | 命中即改 | 缩短、拉远、切至反应 |

> **提示词工程的三条铁律**（与本项目《外部提示词集 AI 可用化改造方法论》一致）：
> 1. **合规是底线，不是优化项**。提示词写得再漂亮，踩线即废。
> 2. **改写优于删除**：保留叙事功能，只换表达方式（§2 各类给了改写示例）。
> 3. **不确定就转人工**，不要自己判断「应该没事」。

### 3.2 机审要求

| 项 | 要求 | 出处 |
|---|---|---|
| 检测方式 | 关键词 + 分类模型 + 人工抽检**三者并用** | GB/T 45654 §7(g) |
| 输入侧 | 对使用者输入信息进行安全性检测 | 同上 |
| 输出侧 | 对生成内容进行安全性检测 | 同上 |
| 触发处置 | 使用者**连续三次或一天内累计五次**输入违法不良信息或明显诱导生成违法不良信息的，应依法依约**暂停提供服务** | GB/T 45654 §7(g)(1) |
| 拒答规则 | 对明显偏激、明显诱导生成违法不良信息的问题**应拒绝回答**；其他问题应均能正常回答 | GB/T 45654 §7(g)(2) |
| 监看人员 | 应设置监看人员，数量与服务规模相匹配 | GB/T 45654 §7(g)(3) |
| 端侧 | 若涉及端侧部署，须具备端侧安全模块、留存安全日志、联网时定期更新词库 | GB/T 45654 端侧条款 |

> **注意误拒率**：GB/T 45654 对**不应拒答**的问题设有 **≤5% 误拒率**上限。**过度拒答同样不合格。** 需在制度中明确「精确拒答」原则，不可一律拒绝敏感话题。

### 3.3 人审要求

| 环节 | 要求 |
|---|---|
| 岗前 | 审核人员须经安全培训与考核合格后上岗，有定期复训与取消资格机制 |
| 职能隔离 | **标注执行与标注审核不得由同一人承担**（GB/T 45654 §5.3(a)(3)） |
| 抽检比例 | 功能性标注逐批人工抽检；安全性标注**每一条至少一名审核人员审核通过** |
| 处置时限 | 有明确的投诉举报处理规则与时限，处理记录完整可查 |
| 台账 | 审核记录须留痕，可追溯——**备案评估必查项** |
| `review` 档 | 词库中 `review` 等级条目**必须人工签核**后方可放行，不得自动通过 |

### 3.5 测试题库与合格率指标（GB/T 45654 附录 B）

**这是备案安全评估的硬门槛，必须达线。**

| 指标 | 要求 |
|---|---|
| 关键词库 | ≥ **10,000 个**；覆盖 A.1+A.2 共 17 类；A.1 每类 ≥200、A.2 每类 ≥100；**至少每周更新** |
| 生成内容测试题库 | ≥ **2,000 题**（覆盖全部模态与语言）；A.1/A.2 每类 ≥50 题，其余 ≥20 题；**每月更新** |
| 拒答测试题库 | 应拒答 **≥500 题** + 不应拒答 **≥500 题** |
| 评估抽样 | 生成内容题人工 + 技术各 ≥1,000 题；每个拒答题库各 ≥300 题 |
| 生成内容合格率 | **≥ 90%** |
| 正确拒答率 | **≥ 95%** |
| 误拒率 | **≤ 5%** |
| 训练数据合格率 | **≥ 96%** |
| 训练数据违法内容占比 | **≤ 5%**（红线，超标不得采集／使用该来源） |
| **违法内容输出率** | **= 0%（绝对红线）** |

> **一票否决制**：训练数据安全、模型输出安全、拒答能力任一维度不通过，**整体评估即不通过**，须整改后重新评估。没有「部分通过」。

## 4. 备案与标识要求

### 4.1 分类分层备案（《微短剧发展管理办法》+ AI 微短剧分类分层标准）

| 档位 | 划分标准（AI 漫剧） | 审核要求 |
