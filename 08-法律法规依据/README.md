## 一、效力层级体系

本项目按效力层级将法源分为四层，**冲突时按"从严原则"执行**（详见 `00-需求\系统级需求\REQ-003_SYS-内容安全尺度与红线口径-最终版.md` 第 0.2 节）：

| 层级 | 名称 | 说明 | 本项目地位 |
| --- | --- | --- | --- |
| **L1** | 法律 | 全国人大常委会制定 | 最高效力，底层义务 |
| **L2** | 行政法规与部门规章 | 国务院 / 部委制定 | 直接监管依据 |
| **L3** | 国家标准 | 强制性 GB / 推荐性 GB/T | 技术实现与评估的操作依据 |
| **L4** | 平台规则 | 分发平台内容规范 | 分发准入条件（不过即不能播出） |

## 五、抓取与维护说明

| 项目 | 说明 |
| --- | --- |
| 抓取工具 | `_tools\fetch_laws.py`（requests + BeautifulSoup），配置见 `_tools\CFG-009_sources.json` |
| 抓取方式 | 直接抓取官方站点 HTML → 提取正文 → 清洗导航 → 转为 Markdown |
| 文件格式 | 统一为：题录表（法规名称/发布机关/发布施行日期/文号/效力层级/来源网址/抓取时间）+ 正文 |
| 重新抓取 | `python fetch_laws.py CFG-009_sources.json`（会自动覆盖同名文件） |
| 复核周期 | L1/L2 法规：**每年**或法规修订时；L4 平台规则：**每季度**或新剧立项前 |

### 已知限制

1. **网络安全法**采用网信办 2016 版全文分页合并，2025 年修正内容单独存档——因国家法律法规数据库（flk.npc.gov.cn）为前端渲染页面，无法直接抓取正文。
2. **国家标准**不提供可抓取的纯文本全文，本目录仅存题录与在线阅览入口。
3. **抖音漫剧规则**无对外公开 URL，需登录平台内查看，本目录仅存题录与项目归纳要点。
4. 抓取文件为**官方站点公开文本**，用于内部合规依据与引用；正式提交备案时，建议以官方原文或购买的标准文本为准。
