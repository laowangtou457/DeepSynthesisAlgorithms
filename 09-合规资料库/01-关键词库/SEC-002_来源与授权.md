## 二、授权路径与留存要求

**国标 §5.1(c) 的表述是「开源许可协议或相关授权文件」——授权有两条合法路径：**

| 路径 | 形态 | 举例 | 举证方式 | 留存要求 |
| --- | --- | --- | --- | --- |
| ① **开源许可协议** | 公开 LICENSE 文件 | MIT / Apache-2.0 | 评估方可自行到仓库核对 | 留存 LICENSE 原文副本 |
| ② **作者直接授权** | 作者单独同意 | funNLP（本项目） | **仅能依赖本项目留存的凭证** | 留存沟通记录／邮件／公开确认 |

### 2.1 许可证留存要求（路径 ①）

| 要求 | 说明 |
| --- | --- |
| 留存位置 | 本目录下 `_licenses/` 子目录，文件名格式 `<来源名>-LICENSE` |
| 留存内容 | 该仓库的 LICENSE 原文（完整，不得删改） |
| 留存时机 | **导入前**先留存，不得后补 |
| 商用确认 | 本项目为商用服务，导入前须逐库确认许可证允许商用 |

### 2.2 直接授权留存要求（路径 ②）

| 要求 | 说明 |
| --- | --- |
| 留存位置 | `../07-第三方词库源/_授权留存/` |
| 留存内容 | 沟通记录截图（含日期与双方身份）／邮件／GitHub Issue 公开留言 |
| 留存时机 | **导入前**先归档；现状为**待补**（见 `../07-第三方词库源/作者授权登记.md` §三） |
| 附带限制 | **不得转授权第三方**；不得据此认为该资源已进入公有领域 |

> ⚠️ **禁止来源**：**既无许可证、又无作者授权**的"网传敏感词库"（如网传的各类"百度敏感词库"）
> **一律不得使用**——无授权依据，且内容准确性不可控，一旦引入错误分类或误伤词，反而推高误拒率。
>
> **注意**：判断标准是「**有无授权**」，不是「**有无 LICENSE 文件**」。
> 有 LICENSE 但内容违法 → 禁用（见 `../04-开源资源索引/SEC-006_开源词库资源.md` §五 禁止清单）；
> 无 LICENSE 但取得作者授权 → 可用（如 funNLP）。
> **两者是独立的两条线，都要过。**
