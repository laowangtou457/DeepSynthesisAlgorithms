## 一、为什么要和 `词表/` 分开

| 目录 | 内容 | 计入国标规模？ |
| --- | --- | --- |
| `../词表/` | 违规内容词条（A1-06、A2-04……） | ✅ **计入** |
| 本目录 | 停用词、拆字、繁简、同义词、否定词、白名单 | ❌ **不计入** |

**混在一起会造成一个严重后果**：把 16 万条领域词当成"词库规模"报上去。
国标要的是**违规内容词条**的规模，不是通用词汇量。**混报会直接被判定为不达标且态度不实。**

所以从物理目录上就分开。

## 三、逐项说明

### 3.1 停用词表

**为什么必需**：关键词匹配若不剔除停用词，「的」「了」「一个」这类高频词会造成大量假阳性，
**误拒率会直接顶穿 5% 的上限**。

**已做的清理**：合并 4 个来源（中文停用词库 / 哈工大 / 四川大学 / 百度），
剔除文件头说明文字、纯符号行、超长散文行，并做了两轮去重
（源文件本身含重复行——川大表有 116 行重复，这是真重复，不是脚本误删）。

### 3.2 拆字表 / 繁简对照表

**这两张表是「防绕过」的基础设施。** 违规内容常常用变体写法规避检测：

| 规避手法 | 依赖的表 | 例子 |
| --- | --- | --- |
| 拆字 | `拆字表.tsv` | 用部件拼字（如「七」→「一 乚」） |
| 繁简 | `繁简对照表.tsv` | 用繁体字写简体违规词 |

两者配合 `gen_variants.py` 可批量生成变体词。**覆盖得越全，违法内容输出率越接近 0%。**

### 3.3 同义词组 —— ⚠️ 使用红线

**这是本目录唯一一个「不能自动使用」的文件。**

一个违规词的同义词**未必也违规**。例如「刀具」与「凶器」可能被归入同组，但只有后者需要拦截。

| 规则 | 说明 |
| --- | --- |
| **一律标 `review` 级** | 同义变体**不得**自动升为 `block` |
| **必须人工复核** | 每条同义变体逐条确认，见 `../../02-生成内容测试题库/SEC-003_判定规程.md` |
| **优先取高置信组** | 组内词义高度一致的优先，宽泛组慎用 |

### 3.4 否定词表

**降误拒的第二个关键工具。** 用于识别否定语境：
「**反对**暴力」「**抵制**色情」是正向表述，不应被拦——但字面上含违规词。

配合语境规则使用，可显著降低误拒率。

### 3.5 白名单-领域词表

12 个领域的正常词汇，出现在文本中**不应被拦截**：

| 领域 | 条目 | 本项目为何特别需要 |
| --- | --- | --- |
| 医学 | 18,749 | 项目涉及毒理、药理（蛊术常被揭示为用毒） |
| 动物 | 17,287 | 项目涉及蛊虫等题材元素 |
| 诗词 | 13,703 | 武侠题材的文风引用 |
| 地名 | 44,804 | 地域词识别与白名单双重用途 |
| 历史名人 | 13,658 | 防真人名誉风险 |
| 法律 / IT / 成语 / 食物 / 财经 / 汽车 / 职业 | 合计 47,530 | 通用白名单 |

> **后四类是本项目的重点**：用户讨论毒理、蛊虫、诗词、地域时被拒答，**正是国标不允许的误拒**。
>
> ⚠️ **白名单只能用于"不拦"，不得反向用于"拦"。** 这是性质限定，写进脚本注释与来源 README。

## 四、使用方式

```bash
# 重新生成（幂等，结果一致）
cd ../../06-构建工具
python import_funnlp.py --dry-run    # 预览
python import_funnlp.py              # 落盘
```

**加工流水线位置**：

```
07-第三方词库源/funNLP/   原始素材
        │  import_funnlp.py
        ▼
01-关键词库/辅助词表/      本目录（工具）
        │  gen_variants.py 引用
        │  expand_lexicon.py 引用（繁简对照表 → 简繁变体；白名单 → 防误伤）
        ▼
01-关键词库/词表/          检测词表（计入规模）
```
