## 五、蛊术玄学类（★ 本项目最关键）

> 平台明令：「作品的核心应该是**破除迷信，提倡科学精神**」；禁止「过度呈现／宣扬**法术玄学**」。
> **核心判据：蛊可以是「名」，不可以是「力」。**

### 5.1 禁止（`block`）

| 词条 | 说明 |
| --- | --- |
| 念咒即成 | 灵验化表述 |
| 法术生效 | 灵验化表述 |
| 蛊虫入体 | 灵验化表述 |
| 蛊术显灵 | 命门级 |
| 下蛊害人（作为真实手段） | 命门级 |
| 施术配方 | 教唆风险 |
| 咒语全文 | 教唆风险 |
| 千年蛊术传承（威力无边） | 宣扬玄学 |

### 5.2 须复核（`review`）与合规写法

| 风险写法 | 合规改写 |
| --- | --- |
| 他念动咒语，蛊虫钻入敌人体内，敌人暴毙 | 敌人饮下那碗药汤后倒下；「蛊」的名头，不过是让人不敢追问的幌子 |
| 蛊术传承千年，威力无边 | 蛊术是这片山地的禁忌传说，村人谈之色变，却无人见过真正的「蛊」 |
| 主角靠蛊术一路无敌 | 主角靠的是对毒理的钻研与对人心的洞察，蛊术只是他借用的名号 |
| 仪式场面完整步骤 | 保留仪式感，**删除可模仿的完整操作步骤** |
| 蛊虫恶心特写 | 暗示、剪影，不恶心特写 |

## 六、地域／民族影射类（★ 本项目高发）

> 对应 A2-01 民族歧视 / A2-04 地域歧视。
> **"某地某族都会下蛊"这类写法会同时踩中玄学红线与歧视红线。**

| 词条／句式 | 处置 |
| --- | --- |
| 某地人都下蛊 | `block` |
| 某族人天生会巫术 | `block` |
| 蛮荒之地（用于贬损现实地域） | `review` |
| 未开化（用于群体） | `review` |
| 穷山恶水出刁民 | `block` |

**写法要求**：架空设定中的门派／族裔／信仰，须与现实群体有**可辨识的距离**；不得使用现实民族、宗教称谓作为反派标签。

## 九、提示词自检十问（写入提示词前逐条过）

1. 是否含禁止档条目？
2. 是否含「伤口／喷血／断肢／创面」类描述？
3. 是否含「以暴制暴／快意恩仇／血洗」类爽感表述？
4. 是否含「念咒即成／法术生效／蛊虫入体」类**灵验**表述？
5. 是否含「畜生／垃圾」等人身侮辱词？
6. 是否有扇耳光／下跪磕头类动作？
7. 是否有大面积露胸露背的服装描述？
8. 是否含未成年人相关的恋爱／暴力／恐怖？
9. 是否含「杀疯了／爽到飞起／爆款／热播／强推」类词？
10. 是否含暴力结果的长时间特写凝视？

> **三条铁律**：① 合规是底线，不是优化项；② 改写优于删除；③ 不确定就转人工。
