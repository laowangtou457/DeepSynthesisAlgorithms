# 第三方词库源

> **本目录存放从外部引入的原始词库资源。**
> 与 `01-关键词库/` 的区别：`01` 放的是**本库自有的、可直接用于检测的词表**；本目录放的是**原始来源素材**，
> 须经加工（见 `../06-构建工具/import_funnlp.py`）才能转为检测资产。
>
> 建立 2026-10-12

---

## 一、为什么单独设这一层

备案评估查两件事：**资产有没有**，以及**资产从哪来、有没有授权**（GB/T 45654—2025 §5.1(c)）。
如果把外部原始素材和自有词表混在一个目录里，第 2 件事就说不清——
**分不清哪些词是我们自己写的，哪些是别人的**。

所以本目录的作用是：**来源隔离**。任何外部素材先落地在这里，留存原始形态与授权凭证，
再经脚本加工进 `01-关键词库/`，加工过程有留痕、可回溯。

也不得带入工程目录。**

- 如后续需要导入政治类词条，**必须按受控流程存入受控区**，不写入工程文档目录。
- 依据：`../05-台账与制度/资产受控与保密说明.md`。

## 五、加工方式

原始素材**不直接用于检测**，须经脚本加工：

```bash
cd ../06-构建工具
python import_funnlp.py --dry-run    # 先看会生成什么
python import_funnlp.py              # 生成加工产物到 01-关键词库/辅助词表/
```

加工产物落在 `../01-关键词库/辅助词表/`，与检测词表分离但同属关键词库资产。

**反向依赖（2026-10-12 补记）**：检测词表的扩充脚本也会**读取**辅助表——
`../06-构建工具/expand_lexicon.py` 用到 `辅助词表/繁简对照表.tsv`（生成简繁变体）与 `辅助词表/白名单-领域词表/`（过滤误伤词）。
因此本目录的来源若作废，处置口径见 `作者授权登记.md` §3.2（**不影响 10,000 词规模达标**）。
