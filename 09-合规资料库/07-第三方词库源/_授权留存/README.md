## 一、为什么需要"证据实体"

授权分两条路径，**举证方式完全不同**：

| 路径 | 举例 | 评估方能否自行核对 | 需要什么 |
| --- | --- | --- | --- |
| ① 开源许可协议 | MIT / Apache-2.0 | ✅ 能——任何人都能到仓库查同一份 LICENSE | LICENSE 副本 |
| ② 作者直接授权 | funNLP | ❌ **不能**——只能依赖本项目提供的凭证 | **授权凭证实体** |

**本目录解决的是路径 ②。** 路径 ① 的 LICENSE 副本存放在 `../../04-开源资源索引/_licenses/`。

> **一句话**：许可证是"公开可查的"，所以只需备一份副本；
> 作者直接授权是"只对我们说的"，所以**必须把说过的话留下来**。

## 三、留存要求

| 项 | 要求 |
| --- | --- |
| 留存时机 | **导入前**归档；当前为事后补录（已如实登记） |
| 文件命名 | `<来源名>-<凭证类型>-<YYYYMMDD>.<扩展名>` |
| 完整性 | 截图须含**完整对话上下文**，不得裁剪到无法辨认时间与主体 |
| 只读性 | 归档后不得修改；如需补充，另存新文件 |
| 访问控制 | 按 `../../../05-台账与制度/SEC-012_资产受控与保密说明.md` 管理 |
| 留存期限 | **不少于服务存续期 + 法规要求的保存年限** |

## 四、如果最终无法补齐

**处置方式**（已写入 `../作者授权登记.md` §3.2）：

1. 将 `../funNLP/` 整个目录移出合规资料库；
2. 已加工出的产物 `../../01-关键词库/辅助词表/` 一并作废；
3. 在 `../../../05-台账与制度/SEC-011_词库更新台账.md` 登记作废原因与日期。

> **但请注意：这不影响达标进度。**
> 辅助表（停用词／拆字／繁简／同义词／否定词／白名单）**不是国标要求的必须资产**，
> 也**不计入 10,000 词的规模指标**。它们提升的是检测精度。
> 因此即使被迫移除，**损失的是精度，不是合规性**。
