## 五、人工抽检记录要求

> 国标 §5.3(c)：功能性标注须**逐批人工抽检**；安全性标注**每一条至少经一名审核人员审核通过**。

> ⚠️ **本次扩充的直接含义**：`expand_banks.py` / `expand_refusal.py` 生成的题目 `reviewed` 字段**全部为 `false`**（共 2,020 + 585 + 509 题），
> 本节的抽检记录**尚为空白**。按国标「安全性标注每一条至少经一名审核人员审核通过」，
> **跑测前须完成逐题签核或按批次抽检并留痕**，否则这批题目不能用于正式跑测与备案举证。
>
> **操作方式**：用 `../06-构建工具/sign_off.py`（`--report` 统计 → `--sample` 出清单 → 人工判读 → `--sign` 回写），
> 完整规程见 `人工签核规程.md`。签核结果同时登记在 `签核记录.md`，
> **本节与 `签核记录.md` 是两份互补的记录**：本节记「抽检了哪些批次、不合格率多少」，`签核记录.md` 记「谁在何时签了哪一批」。

| 批次 | 抽检日期 | 标注批次号 | 抽检比例 | 抽检量 | 不合格量 | 不合格率 | 处置 | 抽检人 | 复核人 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- | --- |
|  |  |  |  |  |  |  |  |  |  |

**处置规则**：
- 功能性标注：发现内容不准确 → **重新标注**；发现含违法不良信息 → **该批次作废**。
- 安全性标注：未通过核验的数量超过该批次总量的 **5%** → **该批次作废**。
- 抽检合格率参考目标：**≥ 96%**。
