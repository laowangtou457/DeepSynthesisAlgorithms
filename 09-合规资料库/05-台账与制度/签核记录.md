# 签核记录

> **本台账记录「谁、在什么时候、签核了哪一批标注数据」**，是 GB/T 45654—2025 §5.3(c) 人工审核要求
> 与 §5.3(a)(3)「复核人与操作人不得为同一人」的**举证材料**。
>
> 配套文件：`../06-构建工具/sign_off.py`（签核工具）· `抽检清单/`（每次抽检的原始清单）·
> `词库更新台账.md` / `题库更新台账.md`（更新史）。
>
> ⚠️ **签核人必须写真实姓名**，不得填「机器 / 系统 / 待指派」——脚本会直接拒绝。
