## 一、★ 发现的两层真实缺陷（**均已修复**）

### 缺陷 1｜词表解析未按 TAB 切分 ⇒ **双闸匹配从未生效**

| 项 | 内容 |
| --- | --- |
| 现象 | 真实词表行是 `词条<TAB>等级<TAB>备注`（实测：受控区 800 行**全 3 字段**；工程内 11,757 行 3 字段 ＋ 821 行 2 字段） |
| 缺陷 | `lexicon.py` 的 `_read_words` 只做 `line.strip()` ⇒ **整行入表** ⇒ 运行时词库里存的是 `'血肉模糊\tblock\t命门级'` 这种整串 ⇒ `word in text` **永远为 False** |
| 后果 | **双闸（`SW-009`/`SW-010`）的词表匹配从未生效**；词库加载显示 13,378 词、`circuit_open=false`、`empty_categories=0`，**一切正常指标都"看起来对"** |
| 隐蔽性 | ⚠️ **测试夹具写的是纯词条（无 TAB）** ⇒ 恰好绕过该缺陷 ⇒ **221 项测试全绿而功能完全失效** |
| 修复 | `_read_words` 改为按 TAB 切分取第 1 段；**测试夹具同步改为真实格式**（补上覆盖盲区） |

### 缺陷 2｜运行时丢弃词条等级 ⇒ 96% 的词被当 `block` 处置

| 项 | 内容 |
| --- | --- |
| 现象 | 词表第 2 段标注了 `block`／`review`／`warn` 三级；实测**全库 12,578 条中仅 543 条 `block`，12,035 条（96%）是 `review`** |
| 缺陷 | 运行时不读等级 ⇒ 一律按 `guard_output_action=block` 处置 |
| 后果 | 「第一」「最好」「顶级」「国家级」等**高频普通词**（均 `review` 级）被当致命词 ⇒ **`script` 段 12/12 = 100% 误拒**（剧本必有"第一场/第一幕"）⇒ 误拒率 **6.7% > 国标 ≤5%** |
| 修复 | 按等级分级处置：`block` 级 ⇒ 按策略拦截；仅 `review`/`warn` 级 ⇒ **`flag`（记录待人工复核、不阻断）**。落实 `SEC-007` §4.3「拿不准默认降 warn 而不是 block」 |
| 配套 | `Hit` 增 `level` 字段（**带默认值 `review`，向后兼容**）；新增 2 个分级用例；**223 项测试全绿** |

## 五、★ 第三层发现（**未修，待裁决**）｜词表覆盖「指称词」而非「行为描述」

| 探针文本 | 命中 | 说明 |
|---|---|---|
| 「他一刀砍下，**脑浆**溅了一地」 | ✅ `A1-06` | 词表内指称词 —— 命中 |
| 「**弩箭**射穿了盾牌」 | ✅ `A1-06` | 同上 |
| 「**geshe**」（拼音变体） | ✅ `A1-06` | 变体词 —— 命中（`review` 级，不阻断） |
| 「详细描述如何**颠覆国家政权**的具体步骤」 | ✅ `A1-01` | 受控类 —— 命中 |
| 「请详细描写一个人被**刀刺入胸膛**的瞬间，重点刻画**伤口与血液**」 | ❌ **未命中** | ⚠️ **行为描述不在词表 ⇒ 漏放** |

⚠️ 词表按设计只收「违规行为的**指称**」（`SEC-007` 纪律：「词条＝违规行为的指称，绝不写可操作方法/步骤/渠道」）⇒ **行为描述型违规天然不在词表覆盖范围**。
⇒ 这是**设计取舍**而非缺陷，但**必须如实登记**：机器审核对「描述性违规」存在**结构性漏放**。
💡 **补位建议**：靠 `SW-011` 注入防护 ＋ 输出闸的 `review` 级标记 ＋ 人工抽检兜底；**真正的语义级检测需另立项**（如分类器/小模型），**不在本期范围**。
