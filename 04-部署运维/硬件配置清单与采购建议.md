## 4 采购注意点（踩坑清单）

### 4.1 GPU

| 注意点 | 说明 |
| --- | --- |
| **消费级卡 vs 专业卡** | GeForce 系列（如 RTX 4090）**无 ECC、无数据中心许可**，部分托管机房拒收此类卡。自建工作站可用；一旦要进托管机房，须提前确认机房政策 |
| **2×24 GiB ≠ 1×48 GiB** | vLLM 张量并行（`tensor_parallel_size=2`）要求卡间高带宽互联。消费级卡**无 NVLink**，跨卡通信走 PCIe，推理效率明显低于同等单卡显存。**若目标是等效 48 GiB，优先单卡 48 GiB** |
| **计算能力门槛** | 必须 Ampere 及以上（≥8.0）。Turing 代不支持 BF16，属不推荐路径 |
| **驱动与 CUDA 版本** | 须与 vLLM 要求的 CUDA 版本匹配；采购时确认可升级到目标驱动版本 |
| **卡长与风道** | 高功耗卡长度常超 300 mm，须核对机箱与主板空间；涡轮卡（服务器型）与轴流卡（工作站型）风道要求不同，混装会过热 |
| **不要用矿卡/无保卡做生产设备** | 24 小时连续推理对稳定性要求高，故障后无保修会直接造成服务中断 |

### 4.2 内存与存储

| 注意点 | 说明 |
| --- | --- |
| **优先升内存** | 内存升级成本低、对并发与加载稳定性收益直接，**排在 GPU 升级之前** |
| **NVMe 的 TBW** | 日志与向量库写入量大，须关注 SSD 的 TBW（总写入字节）指标，消费级盘长期高写入会缩短寿命 |
| **M.2 槽位与 PCIe 通道** | 多块 NVMe 需核对主板 M.2 槽位与 PCIe 通道数；不足时用 PCIe 转接卡，注意是否降速 |
| **RAID1 的可靠性** | RAID1 防单盘故障，**不等于备份**——误删与勒索同样会同步。备份介质必须独立（HW-008） |
| **独立日志分区** | 按 D-014 HW-007，日志分区须与业务数据分开，避免业务写满拖垮审计留存 |

### 4.3 供电、网络与凭证

| 注意点 | 说明 |
| --- | --- |
| **不要用转接线供高功耗卡** | 高功耗卡须用电源原生对应接口，转接线易发热熔毁 |
| **UPS 要能带满载关机** | 按 GPU 满载功率选型，不能只按空载功率；UPS 需支持关机联动 |
| **企业专线 + ICP 是上线阻断项** | **家庭宽带/普通办公宽带不满足 ICP 备案接入要求**，且无固定 IP。微信小程序的服务器域名白名单必须使用**已备案域名**，此项须最先启动（有审核周期） |
| **采购凭证要留存** | 备案举证（HW-017）需要设备型号与序列号，**务必索取发票并登记资产编号** |

| # | 验收项 | 方法 | 通过标准 | ✅ |

| 10 | 电源余量 | 满载电流实测 / 规格核对 | 额定功率 ≥ 峰值 ×1.3 | ☐ |
| 11 | 噪声（办公区） | 满载声级计实测 | ≤55 dB(A) | ☐ |
| 12 | UPS 联动关机 | 拔电模拟 | 能触发优雅关机，恢复后无 PG 异常恢复日志 | ☐ |
| 13 | **模型加载冒烟测试** | 启动 vLLM 加载 Qwen2.5-7B | 加载成功，日志记录 `GPU KV cache size` | ☐ |

| 15 | 登记入账 | 填写 §7 台账 | 台账成册，含序列号与凭证编号 | ☐ |
