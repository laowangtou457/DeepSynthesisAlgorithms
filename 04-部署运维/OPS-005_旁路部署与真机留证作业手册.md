- **可行性成立**：我方服务是标准 FastAPI/uvicorn，可与天枢平台**同机旁路部署**，不侵入平台四容器、不改平台代码；

### 5.4 systemd 用户服务

`~/.config/systemd/user/dsa-app.service`：

```ini

Description=DeepSynthesis Algorithm App (sidecar)
After=network-online.target

[Service]
WorkingDirectory=/home/fxai/Develop/dsa
EnvironmentFile=/home/fxai/Develop/dsa/.env
ExecStart=/home/fxai/Develop/dsa/.venv/bin/uvicorn app.main:app --host 172.18.0.1 --port 8010

# 日志同时进 journal 与 APP_LOG_DIR（应用自带按日轮转）

[Install]
WantedBy=default.target
```

## 七、与平台的两种接入方式

| 方式 | 做法 | 改动量 | 适用 |
| --- | --- | --- | --- |
| **A. 旁路并行**（本次） | 两个服务并存；提示词由我方产出、粘贴/脚本投给平台视频任务；留证在我方侧 | 0（平台零改动） | 立刻可用，真机留证三项全闭环 |
| **B. 渠道化**（后续可选） | 给 app 加 OpenAI 兼容外壳（`/v1/chat/completions`），在平台注册渠道（`base_url=http://172.18.0.1:8010`，`api_format=openai`） | 一层适配器＋1 条渠道记录 | 平台用户在平台内直接用我方能力；须先做 `shots`/`shot_artifacts` 字段对照 |

> 平台侧 `CANVAS_ALLOWED_PRIVATE_UPSTREAM_HOSTS` 已含 `172.18.0.1`，方式 B **无需再改 .env**。

## 八、风险与回滚

| 风险 | 处置 |
| --- | --- |
| .17 是生产在用的稳定版 | 只旁路：不重建/不重启平台容器、不改 `.env`、不动隧道；我方服务崩溃不影响平台 |
| 端口暴露 | 绑 `172.18.0.1`（非 `0.0.0.0`），办公网不可达；如需更强隔离再加 nftables |
| 资源占用 | 文本推理走 .17 现有 14B 网关，我方服务本身 CPU/内存占用低（单 uvicorn）；`/` 仅用 7% |
| 日志增长 | `audit.log`/`app.log` 按日轮转、保留 180 天；`delivery_out` 需定期清理旧包（建议保留 90 天） |
| 网络绕行 | 本机 ↔ .17 依赖网关手工路由，**.17 重启后需重加** `sudo ip route add 192.168.20.51/32 via 192.168.20.1 dev eno1` |
| 回滚 | `systemctl --user disable --now dsa-app`；平台侧零改动，无需回滚 |
