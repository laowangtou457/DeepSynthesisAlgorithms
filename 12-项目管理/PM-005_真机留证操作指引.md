## 一、这一步在证明什么

官方第 8 项要看的是「**交付物里真有标识**」，不是「代码里写了标识逻辑」。所以要留两层证据：

| 证据 | 形式 | 证明什么 |
| --- | --- | --- |
| 截图 | PNG | 交付包**实物形态**：目录结构、导出物里的标识文字、清单里的标识字段 |
| 台账 | JSON（`SEC-022`） | **有人真的逐镜核对过**（角色一致性／跨镜连续性），并署名 |

两者缺一，交付门禁都会如实阻断（`human_review.missing`），审核时也无法说明「谁核对的、核对了什么」。

## 二、先跑出一个交付包

### 2.1 起服务（若已在跑则跳过）

```bash
cd E:/深度合成算法工程材料/03-工程代码
"C:/Users/Administrator.DESKTOP-HK5Q0TB/.workbuddy/binaries/python/envs/default/Scripts/python.exe" -m uvicorn app.main:app --host 127.0.0.1 --port 8092
```

> 真机部署另有 `systemd`／容器方式，端口以实际为准；下文以 `8092` 为例。

### 2.2 找一个已完成分镜阶段的会话

```bash
curl -s "http://127.0.0.1:8092/api/v1/tasks" | head -c 800
```

复制返回里某个**已走到 `shot_prompt` 阶段**的 `session_id`（没有就先用界面走一遍：梗概 → 剧本 → 分镜 → 分镜提示词）。

### 2.3 打包

```bash
curl -s -X POST "http://127.0.0.1:8092/api/v1/delivery/pack?session_id=<你的 session_id>" ^
     -H "Content-Type: application/json" -d "{}"
```

返回里记下三个值：

- `pack_id` —— 形如 `FR-PK-20261111-A1B2C3D4`，**台账要填这个**
- `pack_dir` —— 交付包落盘目录（截图要截它）
- `is_preview` —— `true` 表示包里还有未回填占位，属**预演包**

> ⚠️ **看 `is_preview` 再决定走哪条路**：
> - `false` → 正式包，按第三节截图即可。
> - `true` → 预演包。**照样可以截**，但要**同时截下门禁结论**（`gate.blocked` 与 `blocks` 列表）——这反而证明「门禁不静默放行」。截图说明里写明「预演包，含 N 处未回填占位」。

## 三、截三张图（`T-006` 交付四件套）

存到 `11-过程文档/证据/T-006_交付四件套/`，文件名按 `01_交付包目录.png`、`02_导出物标识.png`、`03_清单标识字段.png`。

| # | 截什么 | 画面里必须能看清 |
| --- | --- | --- |
| ① | **交付包目录**：打开 `pack_dir`，切到显示详情／文件名列表 | `manifest.json`、`aigc_meta.json`、`AST-004_compliance_statement.md`、`copyright_declaration_*.md`、**`exports/` 子目录**、`qa/`；窗口标题栏能看出路径 |
| ② | **导出物里的显式标识**：打开 `exports/` 下任取 2~3 个（建议 `*.md` ＋ `*.csv` ＋ 一个 `*.txt`） | 文件里能看到「**本文件由AI生成，已经过合规验证**」字样；TXT 还要能看到 `=== 标识区 ===` 与提示词区两段 |
| ③ | **清单里的标识字段**：打开 `manifest.json`，搜 `exports` | 每个导出物条目里 `explicit_mark` 与 `implicit_mark` 均为 `true`；`files` 数组含 `copyright_declaration_*.md` |

**截图纪律**：① 不要出现真实企业名／人名（`{{PROVIDER_CODE}}` 占位是正常的，说明「未回填」）；② 不要把词库条目、密钥、内网 IP 截进去；③ 每张图右下角最好带上系统时间（Windows 截图工具默认不带，可用 `Win+Shift+S` 后手动在图片上标注时间）。

## 四、填人工核对台账（`T-006` 另一项）

1. 若还没有台账文件，复制模板：
   ```bash
   cp "E:/深度合成算法工程材料/09-合规资料库/05-台账与制度/SEC-022_人工核对台账-模板.json" \
      "E:/深度合成算法工程材料/_私密实值/human_review_ledger.json"
   ```
2. 在 `records` 里加一条（`pack_id` 用第 2.3 步记下的值）：

   ```json
   {
     "pack_id": "FR-PK-20261111-A1B2C3D4",
     "no": 18,
     "item": "角色一致性 / 跨镜连续性人工核对",
     "result": "pass",
     "checked_at": "2026-11-11T15:20:00+08:00",
     "operator": "核对人姓名",
     "detail": "15 镜逐镜对比上游剧本，主角发型/服装/场景光位一致，未发现跨镜断裂"
   }
   ```

3. **核对动作本身要真的做**：打开 `pack_dir` 里的分镜提示词导出物，逐镜对照上游剧本看角色与场景是否连贯。`result` 填 `fail` 也可以——**如实记 `fail` 比记假 `pass` 有用得多**，门禁会拦住该包，这正是它存在的意义。

字段规范与独立性要求见 `09-合规资料库/05-台账与制度/SEC-022_人工核对台账-使用说明.md`。
