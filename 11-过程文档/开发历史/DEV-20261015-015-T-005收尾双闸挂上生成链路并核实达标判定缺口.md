## 2 把双闸挂上生成链路（`T-005` 的接线缺口）

### 2.1 问题：分层纪律只落了一半

`DEV-20261015-009` §1 明确本动作的技术内核是分层：

```
端点 → SafetyService（只判定并返回 verdict，不阻断）
    → 编排层（DialogueService）据 verdict 决定阻断或放行
```

但实测（`grep -rn "GUARD_INPUT_BLOCKED\|GUARD_OUTPUT_BLOCKED" app/`）：

| 对象 | 实测状态（挂链前） |
| --- | --- |
| `app/core/errors.py` 的错误码定义 | ✅ 有 |
| `services/safety_service.py` 的判定 | ✅ 有 |
| `api/v1/endpoints/safety.py` 的端点 | ✅ 有 |
| **任何地方 `raise AppError(GUARD_INPUT_BLOCKED, …)`** | ❌ **无** |
| **任何地方 `raise AppError(GUARD_OUTPUT_BLOCKED, …)`** | ❌ **无** |
| `services/dialogue_service.py` 中的 `safety` 字样 | ❌ **0 处** |

⇒ 后果是：**`/safety/inspect` 是个孤立的体检接口**，主链（`advance`／`revise`）生成时**不检输入、也不检输出**。这属于「**同一件事的两个落点没有一次扫全**」家族——`DEV-009` 写了分层**原则**，但没有落**编排层实现**。

### 2.2 处置：两处挂闸 ＋ 唯一口径

| 变更对象 | 变更内容 |
| --- | --- |
| `services/dialogue_service.py` | 新增 `_CLIENT_TEXT_FIELDS`（**10 个客户侧字段**的唯一口径）· `_client_texts()` · `_no_safety()`（默认解析器，**未接线时返回 `None` 而非假装通过**）· `_guard_input()`（`SW-009`＋`SW-011`）· `_guard_output()`（`SW-010`）；构造函数新增 `safety_resolver` 形参（默认 `_no_safety`，**不改既有调用点语义**） |
| `_maybe_generate()` | 在 `plan = self._segment_plan(...)` **之前**挂输入闸（**闸在推理前**），在 `final_text, warnings = _merge_parts(texts)` 之后**合并产物**上挂输出闸；`artifact["safety"] = {"input": …, "output": …}` |
| `revise()` | 修改意见同属**客户输入**，渲染前挂输入闸、产出后挂输出闸；`rec.artifacts[key]["safety"]` 同样留痕 |
| `main.py` | 注入 `safety_resolver=lambda: app.state.safety_service`（**同实例** ＋ **延迟解析**：装配顺序上 `safety_service` 先于 `dialogue_service`，用 lambda 避免顺序耦合） |

### 2.3 三条口径决定（均须可举证）

| # | 决定 | 理由 |
| --- | --- | --- |
| 1 | **输入闸的检测范围＝客户侧自由文本，且显式列出** | **刻意排除**三类：① 上游产物字段（`*_json`／`current_artifact`）——那是**模型产物**，已由**输出闸**复检过，再按「输入」检一遍会把「客户输入」与「模型产出」混为一谈；② 服务层注入的 `pack_meta`——由 `build_pack_meta()` 生成、模型不得编造，不是客户输入；③ 会话内部字段（`session_id` 等） |
| 2 | **命中只落分类码与计数，绝不落命中词明文** | `SW-019` 数据最小化；留痕字段设计为 `hit_categories: [category_id,…]` ＋ `hit_count`，**无 `word` 字段**。`tests/test_safety_chain.py` 有专门用例锁死（`test_generation_trace_never_leaks_hit_words`） |
| 3 | **`enforce=false` 时照样检测、照样留痕，仅不阻断** | 项目方 2026-10-15 决策的受控旁路开关（用于受控词库未就绪期的工程联调）；**旁路 ≠ 静默**——verdict 仍产出并随产物留痕 |

### 2.4 明确的**未做**（不是遗漏，是刻意留在下一环）

- **`replace` 策略的实际替换动作未实现**：`guard_output_action=replace` 时服务层给出 `passed=False` ＋ `action="replace"`，编排层按「非 `flag` ⇒ 抛 `GUARD_OUTPUT_BLOCKED`」处置 ⇒ **实际行为等同 `block`**。语义上「替换」需要一个**替换素材来源**，本工程尚无（词库只到类别码，无替换词表）；**如实记为未实现**，不假装。
- **`SW-017` ④ 澄清路径未实现** —— 见 §5.3（`ISSUE-035` ③）。
