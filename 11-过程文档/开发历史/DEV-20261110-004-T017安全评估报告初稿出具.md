## 4 事故与教训（本批一次自伤，与 11-09 README 事故同族）

用 bash 内联 python 改 `PM-001` 时，`io.open(...).read()` 未指定 `newline=''` ⇒ **universal newline 把全文件 CRLF 归一化为 LF**，diff 瞬间膨胀至 **397/396** 假差异（MEMORY §八坑的又一变体：此前只警惕 Edit 工具与 heredoc，本次是「读-改-写三段内联」路径）。**修复**：从 HEAD 字节重建基线，二进制锚点断言（`count==1`）后重做三处编辑，终态 diff **3+/2-**、CRLF 396→**397** 守恒（+1＝新增变更行）。**硬纪律升格**：凡改台账/长文档，**读、写两段都必须 `newline=''` 或纯二进制**，缺一即可能全文件 EOL 翻转。
