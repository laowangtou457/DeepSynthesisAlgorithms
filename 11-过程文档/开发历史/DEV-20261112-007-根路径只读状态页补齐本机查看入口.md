## 一、问题

本机旁路预演实例（`127.0.0.1:8010`）经浏览器访问 `/` 返回 **404**。服务本身健康（`/health`、`/ready`、`/docs` 均 200，`app_initialized` 日志正常），但**根路径无页面**，人工查看时极易被误判为「没起来 / 挂掉了」。2026-11-12 11:35 项目方实际访问即遇到此情形（`_app_local.log` 记 `GET / 404`）。

`OPS-005` §三 第 5 步「部署后自检」原仅列 curl 探针，对**人**不友好；真机留证时核对人也要一个可见入口。

## 二、改动

`app/main.py` 新增 `GET /`（`include_in_schema=False`），返回只读状态页：

- **运行状态**：服务状态／提示词模板数／推理后端／词库规模（条数与类别）／空类目录数／受控区叠加（仅布尔）／语义闸启用／词闸 enforce／fail_closed／输出侧动作；
- **可用入口**：`/docs`、`/health`、`/ready`、`/api/v1/templates`、`/api/v1/backends`、`/api/v1/safety/policy`；
- 页面模板为模块级常量 `_INDEX_HTML`，占位符 `__TITLE__`／`__ROWS__`／`__LINKS__`／`__BACKEND__` 替换生成（**不用 `str.format`**，避免 CSS 花括号冲突）。

## 三、边界与合规

| 约束 | 落实 |
| --- | --- |
| 不写业务 | 纯只读渲染，无状态变更、无会话创建 |
| 不进 OpenAPI | `include_in_schema=False`，接口契约（`APP-*`）零变动 |
| 受控区不外泄 | **只呈现布尔 `controlled_loaded`**，不出现受控区路径与任何受控内容（沿用 2026-10-15 项目方口径） |
| 判据水位 | `validate_output.py` R1~R43、`validate_pack.py`、output 字段集**零改动** |
| 后端形态 | 与业务路由同进程同端口，不新增监听 |

## 五、遗留

- 首页显示的后端为 `mock`；本机接 vLLM（`127.0.0.1:8001`）与 .17（`172.18.0.1:8000` Qwen2.5-14B-AWQ）时同一页面自动呈现真实后端值，无需改动。
- 首页**未加鉴权**：当前仅绑 `127.0.0.1`，上 .17 后绑 `172.18.0.1:8010`（办公网不可达）。若后续对办公网开放，须先加鉴权或摘除状态页。
- `r6` 夹具 v2 复验仍在后台跑测（`ab_t101_r6`），结果另行留痕，与本次改动无耦合。
