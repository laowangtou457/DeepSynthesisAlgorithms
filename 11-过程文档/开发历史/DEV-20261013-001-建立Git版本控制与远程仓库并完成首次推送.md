## 5 遗留

1. **远程仓库可见性**：推送时为 public，需在 GitHub 网页端改为 private（见 `DEV-20261013-002`）。
2. **funNLP 授权凭证**：第三方素材作者授权凭证仍待归档；凭证无法补齐时须同时从版本控制移除其派生的辅助词表（处置命令已写入 `.gitignore` 注释）。
3. **脱敏版不可用于监管举证**：`main` 与备案申报材料不一致，举证须用本地完整版（已在根 `README.md` 第〇节明示）。
4. `pre-push` 钩子为**本地钩子，不入库**，更换机器后须重建。
