## 1 为什么必须先解决「样本有效性」

11-03 三份 `PRO-010` 观测产物看起来「七项大多通过」，但**样本是退化的**：

- `obs2`／`obs3` 的**剧本层只出 1 幕 1 场**（`total_est_seconds=90`，而 Σ 场秒 15／18）
- 分镜因此只有 **1 场 / 2–3 镜 / 1 个单元**

`R9`（场号归属）／`R10`（单元镜数）／`R18`（单元边界转场）／`R19`（逐单元统计）在
「单场单单元」下**分支根本不会被触发** ⇒ 在这种样本上判「已修好」是**假绿**。
（这与 `ISSUE-045`／`ISSUE-053` 同源：上游欠产静默继承到下游。）

## 2 方法

**受控上游 ＋ 当前模板 ＋ 同一条渲染路径**，只变随机性：

- 上游：`artifacts/step3_script.json` 的 `script` 正文（**正常样本**：3 幕 5 场 90 秒、5822 字符）
- 模板：磁盘上的 `TPL-010` **v2.2.2**（`PromptRepository` 直接加载，不经服务层改写）
- 采样：模板自带 `sampling`，`guided_decoding_mode=structured_outputs`
- 判据：**直接 import `prompts/validate_output.py` 的规则函数**（**零改动**），逐条单跑
- 脚本：`.wb-e2e/_probe038_storyboard.py`（`P038_RUNS` / `P038_OUT` 可参数化）

共 **16 次生成**（`_probe038` 3 ＋ `_probe038b` 10 ＋ `_probe038c` 6 中的 3），
其中 **5 份为非吸引子**（≥6 镜且多单元）；另加 1 份**真链路**产物（`artifacts_t087_r14/try1`）。

## 4 `R14` 的机制性修复（已落地并实证）

### 4.1 为什么必须换机制

`total_duration_ms` ＝ `Σ shots[].duration_ms`，属**跨字段算术**：

- JSON Schema／受约束解码**在结构上表达不了**（只能约束单字段取值，不能约束「等于另一组字段之和」）
- 提示词路线**四版四错**：v2.2.0 散文条款 → v2.2.1 给自洽字面值 `18200`（被连 `3200` 一起抄）→ v2.2.2 归零 ＋ 算式紧邻示例
- 真机三种样本 **3/3** 的 `total_duration_ms` **恒为 `0`**（照抄骨架）

### 4.2 改了什么

| 文件 | 改动 |
| --- | --- |
| `app/core/config.py` | 新增 `storyboard_derived_backfill: bool = True`（`APP_STORYBOARD_DERIVED_BACKFILL`） |
| `app/services/dialogue_service.py` | 新增 `_apply_derived_backfill()`；在 `_apply_service_truth` **之后、门禁之前**调用（主路径 ＋ 回退路径各一处）；产物新增 `derived_backfill`／`derived_backfill_text_changed` 留痕 |
| `app/.env.example` | 新增该开关及其理由；并把 `service_truth` 注释里「`total_duration_ms` 一字不改」**订正**为「唯一例外、由独立开关控制」 |
| `.wb-e2e/serve8010.py` | 生效配置打印加 `APP_STORYBOARD_DERIVED_BACKFILL`（**前提可举证**） |

设计约束（三条，均已写进代码注释）：

1. **不改判据**：`R14` 一字未动，回填后它判的是「回填结果是否守恒」；
2. **不改创作**：只改一个**由各镜时长唯一决定**的量，镜数／镜时长／运镜均不动；
3. **必须留痕**：模型原值 `original` 与重算值 `computed` 一并入库，否则等于**悄悄改产物**。

非整数 `duration_ms` **不兜底**（那是 `R12`／`R13` 的判定对象），只记 `skipped_non_integer_duration`。

### 4.3 实证

- **单元级**：四用例自测通过（`0 → 15000`／已守恒 `noop`／非整数 `skipped`／非 `storyboard` 不碰）
- **真链路**（`:8016`，`enforce=false`、`retry=off`）：`derived_backfill = {original: 0, computed: 50000, changed: true, shot_count: 10}`；`Σduration = total = 50000`；**`R14` ✅ 通过**
