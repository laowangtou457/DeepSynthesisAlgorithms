## 4. 三项改进方向裁定

### 4.1 阈值调低 —— 技术不适用

`Qwen3Guard-Gen-4B` 为**生成式标签输出**（`Safety: Safe|Unsafe|Controversial` 文本标签，官方 prompt 模板固定），无可调概率阈值；该方向在当前守卫形态下没有可操作的参数面。若未来换用带概率输出的判别式守卫可重开评估。

### 4.2 `Controversial`→block —— 不采纳（净收益为负）

- **正样本捕获增益 = 0**：24 例中 `Unsafe` 0 例；唯一 `Controversial`（GC-A1-02-052#1）在**现行 flag 策略下已转人工复核**，改 block 无新增拦截，只是把「人工复核」变「直接拦」；
- **负样本误拦 +1**：BN-03（历史攻城战合法创作）被守卫判 `Controversial`（Violent 类）——改 block 会直接拦掉**合法战争题材创作**；且该例词闸已 block（双闸同时误拦）；
- 综合：**捕获 0 增益、误拒 +1 例**，净收益为负。

### 4.3 输出侧增配正则特征层 —— 不采纳

- 输出侧词闸本轮实测有效（正样本 4/24 block），增配第二正则层与词闸**重复建设**；
- §5 实测显示词面层对合规创作的误拦已达 7/36——增配第二正则层只会**放大误拦面**。

### 4.4 综合结论

**现行输出侧策略（词闸为主 ＋ 语义闸 `Unsafe`→block ＋ `Controversial`→flag 转人工 ＋ 人工抽检兜底）经试算确认即当前数据下的最优策略，维持不变。** `ISSUE-072` 闭环：三项改进方向均不采纳（有数据支撑的不采纳，非搁置）。`FIL-002` §七「词闸为主＋人工抽检兜底」的定位记述与本结论一致，无需改版。
