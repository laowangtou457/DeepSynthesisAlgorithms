## 1 背景与目标

### 1.1 项目定位

面向互联网信息服务场景，提供**生成合成类（文本合成）算法**服务。本期服务形态为：以**专业 AI 视频提示词导演**智能体的身份，通过**任务式多轮对话**（仿任务对话模式），为 AI 漫剧创作客户提供从故事梗概到分镜提示词的完整文生文生成链路。

### 1.2 核心目标

| 目标 | 说明 |
| --- | --- |
| 主目标 | 完成**生成合成类算法备案**，具备对外公开传播的服务合规能力 |
| 业务目标 | 建成「一句话 → 梗概 → 剧本 → 分镜脚本 → 分镜提示词」任务对话服务，满足客户各类修改需求 |
| 合规定位 | 自部署开源模型 + 二次开发 + 安全护栏 + 内容标识（对应主登记文档 C-001「B 级」） |

## 3 业务流程

```
客户一句话/素材
   → ⓪ 年龄识别与防沉迷提示（`SYS-021`）
        ├─ 识别为未成年人 → 提示监护人陪同；涉及未成年人个人信息处理 → 取得**监护人同意**后方继续
        │                （未取得同意**不得处理**未成年人个人信息；涉未成年人内容走 `SYS-009`/`SYS-010` 加强档）
        └─ 识别为成年人 → 正常进入①
   → ① 任务对话启动（专业AI视频提示词导演智能体）
   → ② 故事梗概生成
   → ③ 对话式修改（按客户要求迭代）
   → ④ 梗概确认（客户确认完整）
   → ⑤ 剧本生成
   → ⑥ 分镜脚本生成（镜头语言标注）
   → ⑦ 分镜提示词生成（AI视频可用提示词集）
   → ⑧ 交付客户 →（下游）AI 视频生成 → 对外公开传播漫剧
```

**标识责任链**：本系统定位为**上游内容生产方**，与下游视频平台**脱钩**——不直连、不代调、不托管成片。本系统的标识义务为：① 生成文本的显式/隐式标识；② 交付时随产物传递 AIGC 元数据块与标识素材包；③ 出具交付合规声明并留档。**视频侧标识的第一责任主体为下游 AI 视频生成工具**（其为视频的生成合成服务提供者），最终由传播平台按《标识办法》§6 核验兜底（见 SYS-016、SYS-018、SYS-019）。

## 4 系统边界

> **本节口径（2026-10-15 重建，`RS-01` / `RS-02`）**：以 §5 的 **21 条条目集**为唯一依据重建——「包含」侧**逐项挂 `SYS-xxx`、不留无归属条目**；「不包含」侧给出**可判定的排除规则**（凡不在 §5 条目集内、且不属于下游承接范围者，即为不包含）；外部依赖按**四列**登记并标注**是否阻断上线**。
>
> **重建前的缺陷（据 `REV-REQ-004-02`）**：① 原「包含」侧仅列 8~10 项能力，`SYS-004/007/008/010/011/012/013/015/017/019/020/021` 等 **12 条在三分中无任何归属**，导致「不包含」的补集**不可判定**、系统边界**不闭合不互斥**；② 外部依赖**登记不全且性质混杂**——宿主平台及其 ICP 备案资质、模型权重、第三方词库三项缺失，而「算法备案申报材料」「法务 / 合规审核支持」实为**内部产物与内部资源**却被登记为外部依赖；③ 全部依赖**均无失效后果与替代路径**。

#### 7.1.1 两点需业务方周知的风险提示

**① 关于 SYS-Q7（不做生成式 AI 服务备案）**

《生成式人工智能服务管理暂行办法》的适用判断依据是「**是否利用生成式 AI 技术向境内公众提供生成文本、图片等服务**」，与是否自研大模型**无直接关系**；本项目面向公众提供文本生成服务，形式上落入该办法适用范围。实践中，对「基于开源基座二次开发的应用层服务」，多地网信办口径为**在算法备案系统内按「生成合成类」备案即可**，与本次决策一致。建议：

- 备案前以**属地网信办口径书面确认一次**，留痕备查；
- 微信小程序平台侧上传备案凭证时，若平台要求「生成式 AI 服务备案」证明，需按平台要求补充材料。

均不影响本期材料准备，但属备案提交阶段的**潜在补充项**。

**② 关于 SYS-Q15（标识文案「已经过合规验证」）**

「本文件由 AI 生成」部分完全符合 GB 45438—2025 的要素要求（含「AI」+「生成」）。但「**已经过合规验证**」属附加表述，有两点风险：① 易被理解为对**内容真实性/合法性**的背书，而标识的立法目的是提示公众「这是 AI 生成、请注意甄别」；② 若内容事后被认定违规，该表述将构成「已自认完成验证」的不利证据。建议表述（供选择，**当前仍按业务方定稿文案实现**）：

| 方案 | 文案 | 说明 |
| --- | --- | --- |
| 推荐 | `本文件由人工智能（AI）生成，请注意甄别` | 完全对齐 GB 要素 + 立法目的 |
| 备选 | `本文件由 AI 生成` | 元数据中另记「已通过安全自检」，画面文案保持中性 |
| 保留原文案 | `本文件由AI生成，已经过合规验证` | 建议同步在用户服务协议中明确「标识仅声明生成来源，不构成内容真实性或合法性承诺」 |
