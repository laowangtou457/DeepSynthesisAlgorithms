# 项目配置管理

> 本目录是**配置管理的唯一出入口**：全工程文件的编号、基线、变更控制与审计规则都在这里定义。
>
> 工程根目录中编号为 **`13-项目配置管理`**；它不参与业务链路，而是**横切**所有目录的治理层。
>
> 建立 2026-10-13

---

## 一、目录用途（为什么单独建这个目录）

工程推进到「业务链路 4/5 段 + 6 个对象走过评审」之后，出现了两个具体问题：

| 问题 | 后果 |
| --- | --- |
| **评审请求 / 评审意见 / 复查记录散落两处**（`10-评审记录/` 与 `11-过程文档/编制要求/`），且**没有统一编号** | 「**某个需求的评审做到哪一步了**」只能靠文件名里的中文描述去认，跨文件引用极易张冠李戴 |
| **全工程文件无统一标识体系** | 新增文件随意命名，历史引用与现状对不上，改动影响面无法评估 |

**因此**：把「标识 + 基线 + 变更控制 + 审计」抽出来，集中到本目录管理。

## 三、两条硬约定

### 1. 文件名 = `<编号>_<原文件名>`

```
<类别码>-<三位流水号>            通用类别，例 TPL-013
REV-<对象标号>-<两位序号>        评审类，例 REV-SW-007-02
```

- **编号一经分配，永不复用**（文件删除 / 归档后号段不回收）；
- 流水号**按类别独立**，引用时**必带类别码**；
- 完整的类别表与取号明细见 `CM-002_文件取号表.md`。

### 2. 改名即同步引用

**引用同步是改名动作的一部分，不是后续补做项**。改名时须在同一动作内：

1. 用 `git mv`（保证 `git log --follow` 可追溯，**不得「删旧 + 建新」**）；
2. 全工程 `grep` 旧名 → 逐一替换（含 `.py` 内的硬编码路径）；
3. 更新 `CM-002` §4 登记；
4. 落 `DEV-*` 留痕。

> **2026-10-13 首次全量执行**：104 份文件统一取号改名，同步 **142 个文件 / 1996 处**引用；
> 改名后三校验器回归结果与改名前**完全一致**（`validate_templates` 57/8/2 · `validate_output` 53/0/0 · 交付门禁 BLOCK 1）。

## 四、评审类（`REV-`）的读法

**看文件名即知「对象 + 阶段」**：

| 序号位 | 含义 |
| --- | --- |
| `-01` | **评审请求书**（我方 → 评审方） |
| `-02` `-03` … | **评审意见**（评审方 → 我方）；预评审（路径 A）在前、独立会话（路径 B）在后 |
| `-0N`（末位） | **复查 / 处置记录**（我方，逐条闭环） |

例：`REV-SW-006-03_storyboard_v1-分镜脚本生成模板-导演视角评审意见-独立会话-复查记录.md`
→ **SW-006 的处置结果**。

对象的标号取**该对象所承载的需求编号**（`synopsis_v1` → `SW-004`）；
非软件需求条目的对象取**其交付物编号**（《分镜提示词交付规范》→ `D-017`、硬件级需求文档 → `D-014`）。

**「做到哪一步」一表看清**：见 `CM-002_文件取号表.md` §5 评审类专表。

## 五、与相邻目录的关系

| 目录 | 与本目录的关系 |
| --- | --- |
| `10-评审记录/` | **评审意见的物理落点**；本目录定义其**编号与命名规则**（`REV-`），并登记其编号明细 |
| `11-过程文档/编制要求/` | **评审请求书的物理落点**；同属 `REV-<对象>-01` |
| `11-过程文档/开发历史/` | **动作留痕**；本目录的每次变更须在此落一份 `DEV-*`（编号沿用既有 `DEV-` 体系，不并入本表流水号） |
| `12-项目管理/` | **任务与问题台账**（`T-###` / `ISSUE-###`）；配置变更须先在任务清单登记，再在本目录取号 |
| 其余全部目录 | 本目录为它们提供**文件编号**与**变更控制规则**（横切） |

## 六、维护方式

| 项 | 规则 |
| --- | --- |
| **取号** | 新增文件时先查 `CM-002` §2 取「下一起始号」，命名后登记 §4 |
| **基线与变更** | 见 `CM-001` §5 / §6；基线变更须经配置控制委员会（算法负责人 + 项目方）批准 |
| **审计** | 见 `CM-001` §8；每次提交前跑三道机器闸门 + 脱敏自检 |
| **版本** | 本目录文件按各自头部版本字段升版，并在文末「变更记录」追加行 |
