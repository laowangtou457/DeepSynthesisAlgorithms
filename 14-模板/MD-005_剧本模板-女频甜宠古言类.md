# MD-005 剧本模板·女频甜宠古言类

> 覆盖子题材：**霸总独宠、先婚后爱、校园纯爱、替嫁真爱、姐弟恋、古言宅斗、王爷王妃、仙侠情缘、团宠萌兽**。
> 市面验证：女频付费主力——低冲突、高甜度；古风分支的「田园、边关、古市集」是 AI 出图优势区，真人短剧很难低成本拍出。

---

## 一、题材画像

| 项 | 取值 |
| --- | --- |
| 受众 | 女性为主（18–35 岁），评论互动高 |
| 单集时长 | 60–120 秒（9:16 竖屏），校园款可短至 60s |
| 推荐画风 | 新海诚 / 京阿尼（校园）、国风原画（古言）、韩系 Webtoon（都市） |
| 核心情绪 | 心动 → 误会拉扯 → 真香 → 双向奔赴 |
| 甜度纪律 | 每 2 集至少 1 个「心动瞬间」兑现；虐不过夜（误会当集解开或留 1 集悬念） |

## 二、核心叙事公式

```
【身份反差】+【初遇冲突】+【误会升级】+【真香打脸】+【心动瞬间】+【下集钩子】
```

- 古言分支替换为：【替嫁/穿越/退婚】+【错位相处】+【宅斗/情敌干扰】+【王爷/仙尊动心】+【双向守护】。

## 三、单集节拍表（90 秒）

| 时间段 | 节拍 | 内容要求 | 镜数 |
| --- | --- | --- | --- |
| 0–3s | 黄金钩子 | 冲突名场面或心动瞬间前置 | 1 |
| 3–20s | 初遇/冲突 | 反差相遇（撞书、退婚、错抱） | 1–2 |
| 20–55s | 误会与拉扯 | 小误会 → 半解 → 新误会，穿插心动细节 | 2–3 |
| 55–80s | 真香/心动兑现 | 男主（或女主）口嫌体正直的瞬间 | 2 |
| 80–90s | 钩子 | 情敌/家族阻力/身世悬念登场 | 1 |

## 四、开头钩子模板

| 类型 | 公式 | 台词示例 |
| --- | --- | --- |
| 打脸开场型 | 受气女主爆发 + 更强男主护场 | 「动我的女人，问过我了吗？」 |
| 误会开场型 | 尴尬名场面直给 | 「你踩到我的裙子了……灯，还看着呢。」 |
| 古言错位型 | 替嫁/退婚名场面 | 「这门亲事，我退定了。」 |

## 五、结尾钩子模板

| 类型 | 公式 | 台词示例 |
| --- | --- | --- |
| 情敌登场型 | 对峙中 → 新人物出现 | 「那位是……新来的转学生？」 |
| 身世悬念型 | 信物/旧照特写 | 「这块玉佩，为什么会在我这里？」 |
| 误会未解型 | 撞见半截场景 | 「你和他……是什么关系？」 |

## 六、人设卡模板

| 字段 | 女主 | 男主 |
| --- | --- | --- |
| 外观锁定串 | 固有特征+标志物（梨涡、红绳、耳钉） | 固有特征+标志物（金丝眼镜、朱砂痣） |
| 性格关键词 | ≤ 3 个（元气/清醒/软萌 或 清冷/腹黑） | 霸总/清冷/病娇 选一 |
| 反差设计 | 外表 vs 内心 | 口嫌体正直的具体行为清单（先写 3 条） |
| 心动触发器 | 具体到动作（拨头发、递伞） | 具体到动作（揉头发、挡车流） |

## 七、审核红线

| # | 红线 | 处置 |
| --- | --- | --- |
| 1 | 未成年恋爱 | 校园线明确高中以上/大学设定 |

| 3 | 亲密尺度 | 拉手、对视、拥抱封顶，壁咚不贴身 |
| 4 | 古言宅斗 | 宫斗权谋轻量化，不见酷刑、不见害命细节 |

## 八、AI 出图适配要点

- 心动瞬间固定视觉模板：**逆光光斑 + 樱花/烛光飘落 + 慢推**，形成系列记忆点。
- 双人同框是崩脸重灾区 → 优先「单人特写轮切 + 手部/眼神接触空镜」组接。
- 古言大殿、江南水乡、教室窗边出图稳定，主动把名场面往这些场景安排。
