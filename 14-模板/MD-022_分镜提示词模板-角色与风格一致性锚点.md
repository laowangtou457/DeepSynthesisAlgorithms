# MD-022 分镜提示词模板·角色与风格一致性锚点

> 解决 AI 漫剧第一杀手——**角色变脸、画风漂移**。角色一致性是甲方第一条验收标准（市面流水线共识）；结构对齐本工程 `SPEC-007` §3.3/§3.4（style_bible / characters[] 锚点）与 `TPL-008` 评审结论 SR-01（外观锚只写固有特征）。

---

## 一、角色身份证（绝对固定，永不改）

| 字段 | 填写规则 | 示例 |
| --- | --- | --- |
| 角色名 | 事实类，未提供标「未指定」 | 林默 |
| 性别 | — | 女 |
| 年龄段 | 选 1 档 | 18–22 |
| 身高体型 | 瘦高/匀称/微胖/健壮 | 瘦高 |
| 气质关键词 | ≤ 3 个 | 清冷、果决 |

## 二、外观锁定串（锁脸核心，每镜必带）

三要素缺一不可：**外貌（发型+五官+皮肤）+ 穿搭（风格+颜色）+ 标志物（认人核心，必填）**。

| 字段 | 规则 | 示例 |
| --- | --- | --- |
| 发型发色 | 长度+刘海+颜色 | 齐刘海黑茶色长发 |
| 五官 | ≤ 3 个特征 | 桃花眼、高鼻梁 |
| 皮肤 | 冷白皮/小麦色/暖黄皮 | 冷白皮 |
| 固定穿搭 | 全剧同一套；换装集需另立换装锚 | 白衬衫+黑裙 |
| 标志物 | 必填：泪痣/耳钉/眼镜/红绳/旧疤 | 眼角泪痣 |

**每镜引用模板**：

```
参考 @女主母图，(外观锁定串原文照抄)，临时变量(动作/表情/场景) ≤ 2 个
```

> **临时变量 ≤ 2 个**：一次只改动作/表情/场景中的最多 2 项，改多必崩（市面实测纪律）。

## 三、固有特征规则（SPEC-007 SR-01 评审结论，全库强制）

外观锁定串**只写与场景无关的固有特征**，以下内容一律禁止进入锁定串：

| 禁入项 | 原因 | 正确归属 |
| --- | --- | --- |
| 场景依存状态：湿发、雨渍、泥点、汗 | 只在特定场出现，写了会导致全场景错带 | 逐镜 lighting/画面描述 |
| 情绪与神情 | 每镜变化 | 逐镜表情槽位 |
| 时相与天气依存元素（夕阳轮廓光、雪） | 跨镜漂移主因 | 逐镜 lighting |
| 分时相光照差异 | — | lighting_default + 逐镜 lighting |

> **为什么**：本工程导演视角评审（SR-01）确认——外观锚里混入瞬时状态是**跨镜漂移的直接根因**，且下游无权修改锚（分镜层明令「只引用、不重定义」）。

## 四、全片风格锚（style_bible）

| 字段 | 要求 | 示例 |
| --- | --- | --- |
| 画风 | 从 MD-020 画风库选一，全剧唯一 | 复古国漫漫剧、暖旧色调 |
| 上色方式 | 固定 | 手绘动态漫画、线条干净 |
| 色调 | 固定冷暖倾向 | 复古暖灰调 |
| 画质基准 | 固定 | 4K、细节清晰 |
| 反派/场景配色策略 | 色彩对位设计 | 女主冷色系 / 反派暖艳色系 |

> 风格串与外观串一样遵守「**上游已给出则逐字承继——不改写、不缩略、不换词**」（TPL-008 v2.1.4 实测教训：风格词改写导致 6 处集中漂移）。

## 五、母图→垫图工作流（6 步流水线中的锁脸环节）

| 步骤 | 操作 | 要点 |
| --- | --- | --- |
| 1 | 按角色身份证 + 外观锁定串生成**角色母图**（正面定妆照） | 一角色一张，先出母图再谈分镜 |
| 2 | 补角色三视图（正/侧/背）+ 表情包 | 即梦/Midjourney 参考图功能 |
| 3 | 每次生成分镜图：垫母图 + 锁 Seed + 完整重复外观锁定串 | 市面纪律：每镜必带，不省略 |
| 4 | 异兽/机甲等非人主体同样出设定图（多角度） | MD-003 设定类必须出值 |
| 5 | 场景母图（高频场景各 1 张）同理锁定 | 教室窗边、豪门客厅、土炕灶台 |
| 6 | 母图不满意**先回炉母图**，禁止「先凑合用后面再修」 | 后面全是废卡 |

## 六、一致性自检清单

| --- | --- | --- |
| 1 | 每个角色都有母图 + 外观锁定串 + 标志物？ | □ |

| 3 | 每镜临时变量 ≤ 2 个？ | □ |
