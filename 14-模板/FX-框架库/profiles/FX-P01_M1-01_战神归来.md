## 二、基准时长与伸缩规则

### 2.1 骨架口径矛盾（必须交代）

| 来源 | 给的口径 | 冲突点 |
| --- | --- | --- |
| `FX-010` §二 / `fx_framework.yaml` §三 `genres[M1-01].episode_seconds` | 区间 `[90,120]` | 区间不是单一值 |
| `FX-030` §七 `beat_sheet` 填写规则 | `dur_s` 之和 **= 单集秒数**（单一值） | 无法把区间直接灌进 `Σdur_s` |
| `FX-030` §五 `R-S7` / gate P07 | `Σ est_seconds` 严格相等，禁止「约等于」 | 复算需要唯一基准 |

**结论：本档案选定基准单集秒数 = 90，`Σdur_s = 90`。** 120 只作为派生上限，不进入 `beat_sheet` 字段。

### 2.2 选 90 的三条理由

1. **唯一有完整逐拍复算依据的时长**。`MD-002` §三给出「90 秒 × 8 镜示例」六段节拍表；`MD-011` §一给出「90 秒标准版」四段式，§二给出 `S01~S08` 逐镜填空表并附 `Σ est_seconds = 90` 自检算式。两者都是可直接逐拍复算的现成骨架。
2. **120 秒只有一句话口径，无法机械复算**。`MD-011` §一对 120 秒仅写「C 段拉长至 100s，允许 2 个爽点兑现」，无逐镜表、无 `at_s` 序列、无自检算式。按 `FX-000` 铁律二，不可校验的口径不能当基准。
3. **90 是区间下界且为实测标准版**。`FX-010` §二 / `MD-002` §一 的 `90–120` 是允许区间；`MD-011` §一标题即「90 秒标准版」，60 秒与 120 秒均为其派生版。取标准版为基准、加长版为派生，符合骨架自身的层级。

### 2.3 伸缩规则 `SCALE-90-120`（可执行、可复算）

令 `T ∈ [90,120]`，`λ = (T − 90) / 30`；两张端点表如下：

| 拍 | `code` | `dur_s @90` | `dur_s @120` | 处置 |
| --- | --- | --- | --- | --- |
| 1 | `BEAT_OPEN_HOOK` | 3 | 3 | **秒数不动**（`R-S4` 硬上限 ≤3s，A 段） |
| 2 | `BEAT_CONTRAST` | 7 | 7 | **秒数不动**（B 段） |
| 3 | `BEAT_ESCALATE_1` | 15 | 25 | **拉伸段**（C 段 +10） |
| 4 | `BEAT_ESCALATE_2` | 15 | 25 | **拉伸段**（C 段 +10） |
| 5 | `BEAT_ESCALATE_3` | 15 | 25 | **拉伸段**（C 段 +10） |
| 6 | `BEAT_PAYOFF` | 15 | 25 | **拉伸段**（C 段 +10） |
| 7 | `BEAT_AFTERSHOCK` | 15 | 5 | **压缩段**（D 段余波 −10） |
| 8 | `BEAT_CLOSE_HOOK` | 5 | 5 | **秒数不动**（`R-S3` 定格，D 段） |

- **拉伸哪一段**：仅拍 3/4/5/6（C 段，升级×3 + 兑现×1）。依据 `MD-011` §一「120 秒加长版：C 段拉长至 100s」。四拍合计 `25×4 = 100`，与 `MD-011` §一 的 C=100 一致。
- **哪几段秒数不动**：拍 1（3s）、拍 2（7s）、拍 8（5s）。拍 1 受 `R-S4` 约束，拍 8 受 `R-S3` 约束，均不得拉伸。
- **压缩段**：拍 7（余波 15→5s）。`MD-011` §一 四段式在 `T=120` 时 `A3+B7+C100 = 110`，`D = 10s`；本档案把 D 拆为「余波 5s + 定格钩子 5s」，故余波让出 10s 给 C 段。
- **中间时长插值算式**（保证 `Σdur_s = T`）：

```
d0[i] = floor( dur90[i] + λ × (dur120[i] − dur90[i]) )   # 补余前
r     = T − Σ d0[i]                                      # 补余前余数
d[i]  = d0[i] + a[i]                                     # a[i] 为分配量，Σ a[i] = r
at_s[i] = Σ_{j<i} d[j]    # 前缀和重算，天然首尾相接
Σ d[i] = T                # 补余后守恒（不再写 "+ r"，避免补余前后重复计数）
```

- **余数分配规则**（2026-11-25 P0 整改）：`r` 依次分给**升级拍 3 / 4 / 5** 各 `+1`，直到分完；**只有 `r>3` 时**余量才给拍 6（`BEAT_PAYOFF`）。在 `T∈[90,120]` 整数域内实测 `r ∈ {0,2,3}`（分布 11 / 10 / 10），故 **拍 6 永不参与补余**，「任一升级拍 ≥ 兑现拍」恒成立。
- **验收口径澄清**：`各拍 ≤ 端点表对应值` 应理解为 `d[i]` 落在 `dur90[i]` 与 `dur120[i]` 构成的**闭区间** `[min, max]` 内。拍 7 是压缩段（`@90=15 → @120=5`），若按字面 `d[7] ≤ dur120[7]=5` 判，会把 `T=90` 端点本身误判失败。
- **中间点试算**：`T=91`（`λ=1/30`）→ `d0=[3,7,15,15,15,15,14,5]`，`r=2` → `d=[3,7,16,16,15,15,14,5]`，升级 `16/16/15 ≥` 兑现 `15`；`T=119`（`λ=29/30`）→ `d0=[3,7,24,24,24,24,5,5]`，`r=3` → `d=[3,7,25,25,25,24,5,5]`，升级 `25/25/25 ≥` 兑现 `24`。

- **T=120 派生表**：`at_s/dur_s` = `0/3, 3/7, 10/25, 35/25, 60/25, 85/25, 110/5, 115/5`；`Σ = 3+7+25+25+25+25+5+5 = 120`。`at_s` 校验：`0+3=3, 3+7=10, 10+25=35, 35+25=60, 60+25=85, 85+25=110, 110+5=115, 115+5=120`。
- **T=105 试算**（`λ=0.5`）：`d = [3,7,20,20,20,20,10,5]`，`Σ=105`，`r=0`。
- **不新增字段**：派生表只在本文本小节描述，**不写入 `beat_sheet`**；`beat_sheet` 恒为 90 秒基准表（§三）。
- **`min_per_ep` 不随 T 变**：本档案恒为 1。`MD-011` §一「允许 2 个爽点兑现」与 `payoff.min_per_ep` 单一值冲突，骨架无按 T 缩放字段，见遗留问题 `L-09`；本档案不自行变更。

### 3.1 自校验算式（逐条复算）

```
① Σdur_s = 3+7+15+15+15+15+15+5 = 90 == 基准 90              ✓ R-S7 / P07
② at_s = [0,3,10,25,40,55,70,85]，严格递增                    ✓
③ ∀i: at_s[i]+dur_s[i] = at_s[i+1]；
   0+3=3, 3+7=10, 10+15=25, 25+15=40, 40+15=55,
   55+15=70, 70+15=85；末拍 85+5=90 = 总长
   → 无重叠、无空隙                                              ✓ P06
④ 首拍 dur_s=3 ≤3 且 code 含 "OPEN"（BEAT_OPEN_HOOK）            ✓ R-S4 数值 / 事实登记
⑤ 末拍 code 含 "CLOSE"（BEAT_CLOSE_HOOK），purpose=断点           ✓ R-S3 形态 / 事实登记
⑥ is_payoff=true 计数 = 1（仅拍 6）≥ payoff.min_per_ep = 1        ✓ R-S1 / P09（下限）
⑦ purpose="兑现" 计数 = 1，与 is_payoff 计数一致（两套复算同值）  ✓
⑧ 8 个 BEAT_* code 互不重复；与 OPEN_*/CLOSE_*/RL_* 亦不重复      ✓
```

**P0-3 伸缩算式复算**（主理人独立脚本，`dur90=[3,7,15,15,15,15,15,5]`、`dur120=[3,7,25,25,25,25,5,5]`）：
`T=90..120` 全部 **31 个整数点、0 失败**；逐点满足 `Σ d[i] = T`、`at_s` 首尾相接、兑现拍 `≤` 任一升级拍、各拍落在 `[min(dur90[i],dur120[i]), max(dur90[i],dur120[i])]` 闭区间内。
`r` 取值分布 `{0: 11, 2: 10, 3: 10}`，`r ∈ {0,2,3}` 恒 ≤3 ⇒ **拍 6 永不参与补余**。
对照 v1.x：旧算式在 31 点中 **20 点失败**（独立评审 §7.1 只采样 8 点、命中 5 点）。
