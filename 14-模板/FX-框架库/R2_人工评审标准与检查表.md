## 一、为什么机检全绿还要人判
沿用 `R1 §一` 的三层分层：

```
判据回归（19/19）→ 判「判据自身对不对」
机检（10/10 全绿）  → 判「结构对不对、算术自不自洽、字段齐不齐」
人判（本轮要做）    → 判「这套参数像不像这个类型、无依据的取值能不能接受」
```

`FX-000` 铁律二把参数锁成「枚举 / 数值 / 引用」，代价是**「像不像寒门赘婿」机器永远判不了** —— `tone_codes=[SOFT,SHY,VOW]` 每个码都合法，配在悬疑怪谈上就是错的。

R1 完成的是 `FX-P01` 单型；9 型是批量生成，机器能证明「彼此不整组雷同」，**证明不了「M1-02 像寒门赘婿、S1-02 像鬼节轮回」**。所以本轮不是重跑机检，而是补上机器判不了的那半边。
