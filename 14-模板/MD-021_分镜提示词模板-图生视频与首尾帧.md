# MD-021 分镜提示词模板·图生视频与首尾帧

> 从静态分镜图生成视频片段的运镜指令模板。适用可灵、即梦、Seedance 等图生视频工具。
> 核心纪律（市面实务验证）：**只描述运动**、**单镜只写一种主运动**、**首尾帧串镜**。

---

## 一、万能视频公式

```
【景别】【单一运镜】，【主体】在【场景】【时间】做【连续动作】，【光线色调】，【风格】，排除：【排除项】
```

**完整示例**：

```
中景，缓慢推近。一名30岁短发男性（深灰西装）转身望向窗外，
雨滴滑过玻璃，室内暖光，写实电影感，
排除：肢体变形、模糊、多余手指
```

## 二、分段式提示词（即梦/可灵 10 秒镜头标准写法）

把镜头动作按时间分段写，工具按时间轴执行（市面即梦/可灵实务模板）：

```
参考首帧图。
0-3 秒：画面基本保持首帧构图，【环境动态：窗帘被风轻轻吹动】；
3-7 秒：【主体动作：人物缓缓转头看向镜头】，【一种运镜：镜头缓慢向前推进】；
7-10 秒：动作放缓并定格在主体上。
风格：【电影感，自然光，浅景深，胶片色调】。
保持主体外观与首帧一致，避免肢体变形、画面闪烁和多余文字。
```

**完整示例（年代剧）**：

```
参考首帧图。
0-3 秒：男人静坐抽烟，窗外的老式路灯闪烁了一下；
3-7 秒：他缓缓转过头看向窗外，手里烟灰掉落，镜头缓慢推近；
7-10 秒：动作放缓，定格在他凝视窗外的侧脸。
风格：电影级光影，暗部偏暖黄，高光带褪色感，胶片颗粒。
避免液体穿模、人物变形和多余文字。
```

## 三、单一运镜铁律

| 规则 | 原因 |
| --- | --- |
| 1 个镜头只写 **1 种主运动** | 推+摇同时出现会导致画面漂移（市面实测） |
| 工具提供运镜按钮时，**二选一**：用按钮就不在提示词里再写运镜 | 双通道运镜冲突 |
| 快速运镜选 5 秒时长，常规运镜选 10 秒 | 短时长跑不稳快运镜 |
| 运镜枚举（与 MD-010 一致） | 推 / 拉 / 摇 / 移 / 跟 / 固定 / 升 / 降 |

## 四、首尾帧串镜法（角色一致性的视频侧保险）

| 步骤 | 操作 |
| --- | --- |
| 1 | 上一镜的**尾帧图**作为下一镜的**首帧图**（即梦「首尾帧」模式 / 可灵首尾帧功能） |
| 2 | 场景、人物、风格自动连贯，过渡处用剪映 0.3 秒叠化转场 |
| 3 | 需要固定结尾画面（如人物回头的侧脸）时，单独准备一张尾帧图 |
| 4 | 生成 2–4 次，挑最稳的一条；重点检查：主体变形、换脸、运镜跳动、结尾不稳 |

## 五、动作复杂度约束

| 约束 | 要求 |
| --- | --- |
| 单镜动作数 | 1 个连续动作（与 MD-010 镜级规则一致） |
| 单镜时长 | 4–10 秒最佳；超过 10 秒肢体扭曲、人脸崩坏概率陡增 |
| 人物数量 | 单镜 ≤ 2 人有动作；群演静态化或背影化 |
| 动作选择 | 优先：转头、起身、抬手、行走、落泪；避免：转身 180°、多人交手、精细手部操作 |

## 六、工具差异速查

| 能力 | 即梦 | 可灵 |
| --- | --- | --- |
| 图生视频入口 | 视频生成 | 图生视频 |
| 首尾帧 | 「首尾帧」模式 | 首尾帧功能 |
| 参考图锁定 | 参考图 + Seed 锁定 | 运镜控制按钮 |
| 建议时长 | 常规 10s、快运镜 5s | 同左 |

## 七、排项库（排除项，按题材选用）

| 题材 | 排除项追加 |
| --- | --- |
| 全题材通用 | 肢体变形、模糊、多余手指、画面闪烁、多余文字、水印 |
| 人物特写 | 换脸、五官错位、表情僵硬 |
| 年代/复古 | 画面太新、现代元素穿帮 |
| 修仙/玄幻 | 光效闪烁、粒子糊成一团 |
| 末世 | 画面太干净、色彩过饱和 |
