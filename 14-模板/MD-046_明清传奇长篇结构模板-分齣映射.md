# MD-046 明清传奇长篇结构模板（分齣制 → 连载漫剧分集）

> **拆解依据**：语料库明清传奇 **34 部**（台账 MD-040），实读样本：`0419 浣紗記`（全目录 45 齣逐一核对）、`0107 白兔記`、`0123 荊釵記`（归类）。传奇的分齣制是**连载长篇漫剧 / 短剧季播结构**的古典对应物。

## 一、分齣制的结构资产

### 1. 齣题 = 单集标题模板

浣紗記 45 齣的齣题（目录实读）就是 45 个单集标题，规律：

| 齣序 | 齣题 | 命名规律 |
| --- | --- | --- |
| 第一齣 | 家门 | 开场齣固定叫「家门」= 世界观自述 + 主题预告（现代 = 第 1 集冷开场） |
| 第二齣 | 遊春 | 男女主初遇（糖点开局） |
| 第三齣~第六齣 | 謀吳 / 伐越 / 交戰 / 被圍 | 反派线四连拍：密谋→出兵→交战→受困 |
| 第九齣 / 第十七齣 | 捧心 / 效顰 | 西施线名场面（人物标签时刻） |
| 第二十六齣 | 寄子 | 情感重场（托孤式泪点） |
| 第三十三齣 | 死忠 | 牺牲折点（虐点） |
| 第四十二齣 | 吳刎 | 反派下场（清算） |
| 第四十五齣 | 泛湖 | 大团圆 + 江湖之远式余韵 |

**命名规律总结**：动词或动宾短语（2~3 字）> 主谓短语 > 名词。现代漫剧单集标题直接套用：「謀吳→局中局」「死忠→最后的背影」。

### 2. 双线主副交替

浣紗記以「吴线（奸佞）× 越线（复国）× 施线（西施）」三线轮转，齣级交替无固定比例但**每 4~6 齣必切线**。漫剧连载对应：每 4~6 集切一次 POV，避免单线疲劳。

### 3. 家门开场（自报家门总纲）

第一齣「家门」传统上由副末开场唱一首总纲词，概述全剧——这就是**前情提要 / 花字预告**的祖版。现代漫剧第 1 集冷开场 10 秒旁白直接借用。

## 二、连载分季模板（以浣纱记为例 → 24 集短剧）

| 季 | 对应齣段 | 季主题 | 季末卡点 |
| --- | --- | --- | --- |
| S1 (1-8集) | 齣1-12 | 沦陷与入吴（含遊春糖、被圍低谷） | 西施被献入吴（情感+国仇双钩） |
| S2 (9-16集) | 齣13-30 | 隐忍与内应（养馬/效顰/採蓮等名场面） | 定计反攻（悬念峰值） |
| S3 (17-24集) | 齣31-45 | 反攻与收束（誓師→吳刎→泛湖） | 泛湖归隐（开放式余韵） |

## 三、传奇长篇通用构件

| 构件 | 功能 | 漫剧对应 |
| --- | --- | --- |
| 家门 | 总纲预告 | 第 1 集世界观快闪 |
| 齣题 | 单集标题 | 每集标题卡 |
| 下场诗集句 | 齣末两句收束 | 每集结尾 hook 字幕 |
| 生旦净丑轮唱 | 多 POV | 每 4~6 集切 POV |
| 出目对仗 | 相邻齣题对仗（遊春/效顰） | 标题镜像呼应（卡点集用） |

## 四、与元杂剧单本结构的选用关系

| 项目形态 | 用哪个模板 |
| --- | --- |
| 60~100 集微短剧（付费长线） | 本模板（分齣制 + 三季结构） |
| 6~12 集单完故事 | MD-041 元杂剧四折映射 |
| 单集 90~180 秒 | 齣→集 1:1；折→2~3 集 |
| 剧场版 / 精编版 | 取传奇 3~5 个核心齣重组 |

## 五、实拆数据核对表

浣纱记全本 45 齣目录已逐条录入本工程（本文件§一仅摘示例 9 条，全表见 MD-040 台账与语料源 `0419_浣紗記.txt` 目录段）。核对要点：齣题均 2~3 字动宾结构；情感重场（寄子/死忠/吳刎/泛湖）分布均匀，间隔 7~9 齣——**连载剧泪点间隔 7~9 集**直接由此得出。
