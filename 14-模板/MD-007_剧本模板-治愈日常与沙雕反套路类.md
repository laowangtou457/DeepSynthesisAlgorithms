# MD-007 剧本模板·治愈日常与沙雕反套路类

> 覆盖子题材：**萌宠治愈、家庭温情、职场轻奇幻、沙雕脑洞、穿书反套路、国风志怪**。
> 市面验证：治愈是「点赞收藏之王」，沙雕反套路传播快、过审轻松、制作难度最低——新手试水与泛流量首选。

---

## 一、题材画像

| 项 | 取值 |
| --- | --- |
| 受众 | 泛流量（治愈偏女性、沙雕偏年轻） |
| 单集时长 | 60–90 秒（沙雕可短至 45s） |
| 推荐画风 | 吉卜力（治愈）/ 极简沙雕漫（反套路）/ 国风水墨（志怪） |
| 核心情绪 | 治愈线：共鸣 → 温暖 → 释然；沙雕线：预期违背 → 笑点 → 反转爽 |
| 系列性 | 单集独立成篇 + 固定主角组合（观众为「老朋友」回访） |

## 二、核心叙事公式

| 线 | 公式 |
| --- | --- |
| 治愈 | 【现实困境】+【意外相遇】+【温暖互动】+【心结解开】+【双向救赎】+【美好展望】 |
| 沙雕反套路 | 【熟悉套路开场】+【第一步偏离】+【步步颠覆】+【反逻辑收尾】+【下一集预告式笑点】 |
| 穿书反套路 | 穿成炮灰/恶毒配角 → 拒绝按剧情走 → 改写结局 → 原著剧情崩坏喜剧化 |
| 国风志怪 | 志怪传说 → 人兽/人妖相遇 → 情义小故事 → 余韵收尾（聊斋式） |

## 三、单集节拍表（60 秒）

| 时间段 | 节拍 | 治愈线 | 沙雕线 | 镜数 |
| --- | --- | --- | --- | --- |
| 0–3s | 钩子 | 扎心提问/困境画面 | 反常识画面 | 1 |
| 3–20s | 建立 | 困境铺满（被开除、深夜加班） | 套路正常铺陈 | 1–2 |
| 20–40s | 转折 | 小动物/陌生人/旧物出现 | 第一步偏离套路 | 2 |
| 40–55s | 兑现 | 温暖互动细节（蹭裤腿、递牛奶） | 步步颠覆 + 笑点密集段 | 2 |
| 55–60s | 收尾 | 释然定格 + 展望 | 反逻辑定格 | 1 |

## 四、开头钩子模板

| 类型 | 公式 | 台词/旁白示例 |
| --- | --- | --- |
| 扎心提问型 | 普世困境 + 数字化自嘲 | 「30 岁还没存款，是不是很失败？」 |
| 反常识型 | 画面即笑点 | 猫戴着领带开晨会 |
| 套路假开场 | 像极熟悉的爽文桥段 | 「我叫林小柔，是全书最恶毒的女配。」 |

## 五、结尾钩子模板

| 类型 | 公式 | 示例 |
| --- | --- | --- |
| 展望型 | 时间跳切 + 成长画面 | 一年后她成了宠物博主 |
| 反逻辑型 | 预期再次违背 | 反派哭着说「其实我是来应聘的」 |
| 系列预告型 | 固定搭档新冒险 | 「下周一，它又要开会了。」 |

## 六、人设卡模板（治愈线动物/沙雕线角色）

| 字段 | 要求 |
| --- | --- |
| 外观锁定串 | 动物须写死品种、毛色、残疾/标记（断了一条腿的橘猫）——**残疾标记是共情锚** |
| 性格关键词 | ≤ 3 个；沙雕角色给一条「永远认真做荒谬事」的行事原则 |
| 关系 | 双向救赎结构：谁治愈谁，先写清楚 |
| 口癖/习惯动作 | 沙雕线必填（每集重复出现，系列记忆点） |

## 七、审核红线

| # | 红线 | 处置 |
| --- | --- | --- |
| 1 | 治愈线不贩卖焦虑 | 困境呈现 ≤ 20 秒即转暖 |
| 2 | 沙雕不低俗 | 梗避开擦边、地域黑、职业歧视 |
| 3 | 穿书反套路不引导仇恨 | 反套路是喜剧解构，不实指侮辱真人 |
| 4 | 志怪 | 同 MD-006 红线：不灵异实指，给情义余韵 |

## 八、AI 出图适配要点

- 治愈线是 AI 出图**最稳赛道**：柔光、水彩质感、动物表情容错高；单主角+单场景+单动作。
- 沙雕线用**极简画风**（粗线条、高饱和色块）可显著降低崩脸率与成本。
- 国风志怪用水墨+雾气氛围词，克制用光（一盏灯笼、一窗烛光）。
