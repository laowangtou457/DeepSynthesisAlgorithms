# MD-003 剧本模板·男频玄幻修仙与末世类

> 覆盖子题材：**废柴逆袭修仙、御兽流、系统金手指、末世囤货、规则怪谈/无限流、科幻机甲**。
> 市面验证：男频 TOP1 常青赛道——法术、妖兽、幻境、冰封城市等画面真人剧拍不了，**是 AI 漫剧视觉优势最大的赛道**，适合长线多季 IP。

---

## 一、题材画像

| 项 | 取值 |
| --- | --- |
| 受众 | 年轻男性，粉丝粘性高、愿意追全集 |
| 单集时长 | 90–120 秒（9:16 竖屏） |
| 推荐画风 | 国潮新古风 / 暗黑仙侠 / 末世写实 / 赛博朋克 |
| 核心情绪 | 绝境 → 觉醒 → 升级 → 碾压 |
| 世界观要求 | 必须能支撑 ≥ 12 集连载（升级体系、地图扩展） |

## 二、各子题材叙事公式

| 子题材 | 公式 | 关键节点 |
| --- | --- | --- |
| 废柴逆袭修仙 | 灵根被废 → 奇遇觉醒 → 宗门打脸 → 升级渡劫 | 第 1 集必须完成「觉醒」视觉化（灵光、异兽现身） |
| 御兽流 | 落魄 → 滴血/契约异兽 → 兽魂加持 → 登顶 | 异兽是第二主角，须有独立外观锁定串 |
| 系统金手指 | 穿越绑定 → 签到/任务 → 兑换变强 → 打脸 | 系统面板是高频视觉元素，须固定 UI 风格 |
| 末世囤货 | 重生/预警 → 卖房囤物资 → 建安全基地 → 危机化解 | 「囤货清单」「基地蓝图」是天然爽点画面 |
| 规则怪谈 | 进入副本 → 宣读诡异规则 → 闯关试错 → 真相反转 | 规则文本要逐条上屏（强记忆点） |
| 科幻机甲 | 废铁机甲 → 觉醒契约 → 星际征战 | 机甲设定须出设定图（设计类必须出值） |

## 三、单集节拍表（90 秒）

| 时间段 | 节拍 | 内容要求 | 镜数 |
| --- | --- | --- | --- |

| 3–10s | 转机出现 | 金手指/异兽/系统觉醒的视觉爆点 | 1–2 |

## 四、开头钩子模板

| 类型 | 公式 | 台词示例 |
| --- | --- | --- |

## 六、人设与设定卡（本类特有的「设定类必须出值」清单）

| 设定项 | 归类 | 要求 |
| --- | --- | --- |
| 主角外观锁定串 | 设计类 | 固有特征 + 标志物（额间朱砂、旧疤、玉佩） |
| 异兽/机甲外观 | 设计类 | 体型、鳞甲材质、发光部位、色彩——**逐项写死**，跨镜不得漂移 |
| 功法/系统 UI | 设计类 | 面板配色、字体风格、出现位置固定 |
| 宗门/势力名、地名 | 事实类 | 客户未提供标「未指定」，不得编造真实宗教场所 |
| 修为等级体系 | 设计类 | 等级名与序号全剧一致，登记进风格锚 |

## 七、审核红线

| # | 红线 | 处置 |
| --- | --- | --- |
| 1 | 血腥、丧尸、恐怖画面收敛 | 末世偏「生存基建、智斗」，弃纯丧尸路线 |
| 2 | 禁封建迷信、灵异恐怖 | 规则怪谈走「科幻/心理解释」，禁鬼神实指 |
| 3 | 禁真实宗教场所与仪式 | 宗门架空命名，禁用真实教派词 |
| 4 | 打斗暴力分级 | 兵器撞击、灵光对轰为主，不见断肢 |

## 八、AI 出图适配要点

- **本赛道是 AI 出图优势区**：法术光效、妖兽、幻境、冰封城市优先安排在关键镜。
- 异兽一致性最难 → 先出**异兽设定图（多角度）**再进分镜，全剧垫图。
- 「升级/突破」高光镜固定视觉模板（光柱、涟漪、粒子），形成系列记忆点。
