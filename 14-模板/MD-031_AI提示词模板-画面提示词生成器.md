# MD-031 AI 提示词模板·画面提示词生成器

> **整段复制给任意大模型即可用**：把分镜表转换为 AI 生图提示词（喂给即梦/Midjourney/SD），再把静帧转换为图生视频指令（喂给可灵/即梦）。另附角色设定卡生成 prompt。
> 公式来源：市面 2026 验证的十要素公式与分段式视频模板；角色锚规则承继本工程 `SPEC-007` SR-01 评审结论。

---

## Prompt D · 分镜 → 生图提示词（批量转换）

```
你是 AI 漫剧的画面提示词工程师。请把下面的分镜表逐镜转换为文生图提示词。

【你的输入】
分镜表：{粘贴 MD-030 Prompt C 输出}
风格锚：{粘贴 style_bible，逐字使用}
角色锚定表：{粘贴各角色外观锁定串}

硬性约束：
1. 每条提示词严格按十要素顺序：
   景别 + 角色锚定 + 核心动作 + 场景细节 + 光影 + 风格定位 + 画质 + 稳定约束 + 比例
2. 角色锚定 = 外观锁定串逐字照抄（外貌+穿搭+标志物），不得改写、不缩略、不换词；
   锁定串中禁出现情绪、湿发、天气等瞬时状态——瞬时状态写到光影/动作槽位。
3. 每条只写 1 个核心动作；分镜里有多个动作时拆成多条提示词并标注对应镜号。
4. 场景细节给出 1–2 个具体记忆点，不写空泛词。
5. 光影必写（逆光/柔光/顶光/眩光/侧光之一），并与情绪自洽。
6. 稳定约束必写：面部不崩坏、人体结构正常、背景不穿帮。
7. 比例统一 9:16 竖屏。
8. 每条末尾追加负向提示词：变形， 多余手指， 模糊， 脸崩， 水印， 文字， 背景穿帮

输出格式（逐镜一条，镜号对齐）：
镜号 | 生图提示词全文
```

## Prompt E · 静帧 → 图生视频指令

```
你是 AI 漫剧的视频提示词工程师。请为下面的镜头写出图生视频指令。

【你的输入】
镜头列表：{镜号 + 首帧画面 + 期望动作}
工具：{可灵 / 即梦 / Seedance}
单镜时长：{如 10 秒}

硬性约束：
1. 用分段式写法（按时间轴）：
   0-3 秒：画面基本保持首帧构图，只写环境动态；
   3-7 秒：主体做一个连续动作 + 一种运镜；
   7-{N} 秒：动作放缓并定格在主体上。
2. 全片只允许 1 种主运镜（推/拉/摇/移/跟/固定/升/降选一）；
   若工具提供运镜按钮，提示词里不得再写另一种运镜。
3. 动作选择保守：转头、起身、抬手、行走、落泪为宜；
   禁写转身 180°、多人交手、精细手部操作。
4. 末行必须写：保持主体外观与首帧一致，避免肢体变形、画面闪烁和多余文字。
5. 末行追加题材排除项（通用：变形， 模糊， 多余手指， 画面闪烁， 水印）。

输出格式：
镜号 | 视频指令全文
```

## Prompt F · 角色设定卡生成（开工第一步）

```
你是 AI 漫剧的角色设计师。请根据下面的人设信息，产出「角色母图提示词 + 外观锁定串」。

【你的输入】
角色信息：{姓名/身份/性格/年代背景，可从剧本粘贴}
画风：{如 国潮新古风}

硬性约束：
1. 外观锁定串 = 外貌(发型+五官+皮肤) + 穿搭(风格+颜色) + 标志物(必填)，
   只写与场景无关的固有特征；禁写情绪、湿发、天气、光线。
2. 标志物必须唯一且好画（泪痣/耳钉/眼镜/红绳/旧疤），它是观众认人核心。
3. 配色与全剧风格锚自洽；若该角色是反派，与主角做色彩对位。
4. 一次性输出：①母图提示词（含十要素）②外观锁定串（≤40 字，供每镜引用）
   ③三视图补充说明 ④2 个备选方案。

输出格式：
字段 | 值
母图提示词 |
外观锁定串 |
标志物 |
备选方案A |
备选方案B |
```

```

```
