# MD-042 母题模板库·冤狱公案类（细分 8 式）

> **拆解依据**：语料库中该母题共 **30 部**（台账见 MD-040），实读全本样本：`0115 竇娥冤`、`0037 趙氏孤兒`、`0010 灰欄記`（开头）、`0012 陳州糶米`（开头）。本模板把 30 部冤狱公案剧细分为 8 种叙事式，每式给出：剧情公式、元剧实证、现代漫剧改编要点。

## 一、母题细分总表

| 式名 | 子类 | 剧情公式 | 元剧实证（编号） | 现代漫剧类型 |
| --- | --- | --- | --- | --- |

| B 权奸灭门式 | 满门抄斩型 | 权臣构陷 → 满门抄斩 → 遗孤存活 → 十八年后复仇 | 趙氏孤兒(37)、五侯宴(2) | 男频逆袭 / 复仇 |
| C 智勘辨真式 | 神探断案型 | 两造争一物（子/妻/产）→ 清官设局巧验 → 真相大白 | 灰欄記(10)、蝴蝶夢(7)、合同文字(13) | 悬疑推理 |

## 二、各式剧情节拍（以 A、B、H 三式详拆，其余按公式展开）

### 式 A 屈打成招式（样本：竇娥冤）

| 节拍 | 内容 | 竇娥冤原文证据 | 漫剧时长配比（8 集版） |
| --- | --- | --- | --- |
| A1 施恩设套 | 反派先施救命之恩，再提非分要求 | 张氏父子救蔡婆 → 强逼婆媳招婿 | 1 集 |
| A2 计害嫁祸 | 反派投毒目标错位，反害自家 | 张驴儿下毒 → 老父误饮身亡 | 1 集 |
| A3 二选一威胁 | 「官休 / 私休」强迫抉择 | 「你要官休呵…你要私休呵…」 | 1 集（互动钩子点） |
| A4 昏官断案 | 贪官色厉内荏，严刑逼供 | 桃杌：「人是賤蟲，不打不招」；「但來告狀的，就是我的衣食父母」 | 1 集（讽刺名场面） |
| A5 舍身代罪 | 主角为护他人屈招 | 「住住住，休打我婆婆，情願我招了罷」 | 1 集（泪点） |
| A6 绝境立誓 | 死前抛出不可能的验证 | 三桩誓愿：血溅白练 / 六月飞雪 / 亢旱三年 | 2 集（付费卡点） |
| A7 天道应验 | 誓愿当场应验，留悬念 | 「真個下雪了，有這等異事！」 | 1 集 |
| A8 昭雪清算 | 身居高位的亲人翻案，恶人连坐 | 竇天章刷卷 + 鬼魂告状，张驴儿凌迟、赛卢医充军 | 1 集 |

### 式 B 权奸灭门式（样本：趙氏孤兒）

| 节拍 | 内容 | 原文证据 |
| --- | --- | --- |
| B1 文武构隙 | 反派自述杀心由来 | 屠岸賈楔子独白：神獒设计陷赵盾（草人紫袍驯犬的诡计细节可直用为漫剧"反派智商名场面"） |
| B2 灭门只留一脉 | 三百口诛尽，只留孕妇 | 「將趙盾三百口滿門良賤，誅盡殺絕」 |
| B3 遗孤托孤 | 父死前给孩子取名立誓 | 「我就腹中與他個小名，喚做趙氏孤兒。待他長立成人，與俺父母雪冤報仇」 |
| B4 舍命藏孤 | 忠仆药箱藏孤，公主自缢灭口 | 程嬰药箱、公主「罷罷罷，為母的也相隨一命亡」 |
| B5 生死盘查 | 守门将放行后自悟失职 | 韩厥「程嬰回來…我可搜出人參來也」——三次"叫回"的 suspense 递进 |
| B6 以子易子 | 牺牲亲生骨肉换孤存 | （二折以下，同结构延展） |
| B7 十八年隐忍 | 孤儿认贼作父长大 | |
| B8 集体赴死昭雪 | 众义士连环自证 + 孤儿手刃仇人 | |

**该式的核心资产**：B3 取名立誓 + B4 托孤，是"复仇婴儿开局"的鼻祖——现代漫剧「开局满门被灭只剩一人」的源头公式。

### 式 H 弱女反杀式（样本：望江亭、救風塵节录）

| 节拍 | 内容 | 要点 |
| --- | --- | --- |
| H1 恶权贵锁定目标 | 权贵看上人妻/名妓 | 反派登场用"权势自述"立威 |
| H2 威逼利诱 | 假意抬举实则霸占 | 双面人设，正面观众知晓其底 |
| H3 女主定计 | 假意周旋，设局取证 | 女主智商在线是本式命脉 |
| H4 当众揭发 | 借更高权力反杀 | 「以权制权」结构 |
| H5 恶人自毙 | 恶人搬石砸脚 | 收束要快，一集内完成 |

## 三、公案剧通用构件（8 式共用）

| 构件 | 功能 | 现代化改法 |
| --- | --- | --- |
| 清官双面 | 明面昏聩 / 私下精察（或反之） | 可改为"扮猪吃虎"上司或"隐藏系统" |
| 物证链 | 文书、银两、药渣、信物 | 分镜特写素材清单，每个物证至少给 1 次特写 |
| 三问递进 | 审案三问，层层收紧 | 对话节奏模板：问→答→反问→崩 |
| 翻案窗口 | 一切已绝望时的体制外翻案（鬼魂/上位者/民心） | 现代设定可换成「舆论」「监控」「DNA」 |
| 恶人连坐 | 主犯 + 从犯 + 昏官各得其所 | 结尾清算表：一个反派一行字幕（爽点堆叠） |

## 四、审核红线提示（对照 MD-006/MD-007 红线节）

1. 拷打、血腥翻案镜头：降格为剪影 / 声音暗示，不给正面特写。
2. 鬼魂告状（F 式）：平台差异大，备好「幻觉 / 精神状态」的现实化替代稿。
3. 昏官台词讽刺性极强（衣食父母句），保留讽刺力度但避免映射现实机构名称。
