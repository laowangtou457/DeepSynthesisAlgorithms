# MD-006 剧本模板·悬疑怪谈类

> 覆盖子题材：**轻悬疑、民间奇谈、单元反转推理、规则怪谈**。
> 市面验证：中小团队首选——成本低、完播率强、男女通吃；单集独立可连续剧。⚠️ 红线前置：**不是恐怖鬼片**，主打悬念、反转、细思极恐；禁封建迷信、血腥、灵异恐怖实指。

---

## 一、题材画像

| 项 | 取值 |
| --- | --- |
| 受众 | 男女通吃，晚间流量适配 |
| 单集时长 | 60–90 秒（单元剧每集独立成篇 + 系列世界观钩子） |
| 推荐画风 | 暗黑写实 / 低饱和国漫（详见 MD-020 画风库） |
| 核心情绪 | 好奇 → 不安 → 悬念 → 反转 → 细思极恐 |
| 成本优势 | 场景简单（一屋、一巷、一车），AI 制作省力 |

## 二、核心叙事公式

```
【诡异事件开场】+【主角介入调查】+【第一个线索/反转】+【陷入危险】+【真相浮出一半】+【更大的阴谋】
```

- 单元剧变体：每集一个独立案件/规则副本，结尾 10 秒埋系列钩子（组织、旧照、编号）。

## 三、单集节拍表（75 秒）

| 时间段 | 节拍 | 内容要求 | 镜数 |
| --- | --- | --- | --- |
| 0–3s | 诡异开场 | 超现实画面 + 一句提问式台词 | 1 |
| 3–15s | 介入 | 主角身份与介入理由快速交代 | 1–2 |
| 15–35s | 线索与反转① | 第一个线索落地，第一次认知颠覆 | 2 |
| 35–55s | 危险逼近 | 主角陷入险境，环境异动 | 2 |
| 55–70s | 真相一半 | 揭一半、藏一半 | 1–2 |
| 70–75s | 大阴谋钩子 | 更大格局一句话 + 定格 | 1 |

## 四、开头钩子模板（本类专用：悬念提问型）

| 类型 | 公式 | 台词示例 |
| --- | --- | --- |
| 超现实提问型 | 诡异问题 + 超现实画面 | 「你有没有见过，死人发的朋友圈？」 |
| 限时压迫型 | 诡异场景 + 倒计时 | 「距离下一个死者出现，还有 24 小时。」 |
| 日常异化型 | 熟悉场景 + 一个错误细节 | 「楼道声控灯，今晚第三十一次自己亮了。」 |

## 五、结尾钩子模板

| 类型 | 公式 | 台词示例 |
| --- | --- | --- |
| 反转推翻型 | 以为真相了 → 一句话推翻 | 「真正的凶手，是你最信任的那个人。」 |
| 视角惊悚型 | 画面揭示主角已被观察 | 监控画面里主角身后多了一个影子 |
| 规则违反型 | 队友/自己违反规则 | 「规则三说，不能应门。门开了。」 |

## 七、审核红线（本类最高优先级）

| # | 红线 | 处置 |
| --- | --- | --- |
| 1 | 禁封建迷信、灵异实指 | 一切异象最终给「人为/心理/科幻」解释 |
| 2 | 禁血腥、恐怖画面 | 用声音、影子、缺席、留白制造恐惧 |
| 3 | 禁教唆性细节 | 自杀、作案手法不给可模仿步骤 |
| 4 | 涉警涉法 | 不得虚构真实办案程序细节，结尾正邪有界 |

## 八、AI 出图适配要点

- 恐惧感来自「**熟悉场景 + 错误细节**」：提示词写法是正常场景词 + 单个异常元素（多出的椅子、反常的灯）。
- 暗部细节 AI 易崩 → 大面积阴影 + 一处高光（烛光、手机屏），忌全黑画面。
- 「主角回头」类镜头拆两镜（回头前 / 回头后），不写连续转头动作。
