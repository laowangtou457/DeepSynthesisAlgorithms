# MD-002 剧本模板·男频逆袭类

> 覆盖子题材：**战神归来、赘婿翻身、神医下山、隐世大佬、重生商战、少年逆袭、乡村振兴**。
> 市面验证：男频大盘播放爆发力最强的常青赛道（市面拆解：经典三件套「前期被羞辱 → 隐藏大佬身份 → 当众打脸」）；同质化严重，**必须靠差异化人设突围**。

---

## 一、题材画像

| 项 | 取值 |
| --- | --- |
| 受众 | 中青年男性，下沉市场占比高 |
| 单集时长 | 90–120 秒（9:16 竖屏） |
| 推荐画风 | 韩系 Webtoon / 写实电影感（详见 MD-020 画风库） |
| 付费模式 | 前端免费起量 + 中段卡点付费 |
| 核心情绪 | 压抑 → 反差 → 宣泄（打脸） |
| 配角规模 | 每集 ≤ 3 个有台词角色（人多必崩脸，见 MD-022） |

## 二、核心叙事公式

```
【低谷惨状】+【隐藏身份/金手指埋设】+【第一次打脸】+【升级成长】+【最终复仇/身份揭晓】+【新的挑战】
```

- **三件套铁律**：每集至少兑现一次「羞辱 → 反差铺垫 → 打脸」，不允许整集只铺垫不兑现。
- **身份揭晓节奏**：大身份（战神/首富）留到付费卡点集或大结局；小打脸（亲戚、保安、前台）每集可给。
- **金手指埋设**：第 1 集内必须完成「记忆/系统/传承苏醒」的视觉化瞬间（回眸、握拳、眼神变化）。

## 三、单集节拍表（90 秒 × 8 镜示例）

| 时间段 | 节拍 | 内容要求 | 镜数 |
| --- | --- | --- | --- |
| 0–3s | 黄金钩子 | 极端羞辱或身份反差直接开场，台词 ≤ 12 字 | 1 |
| 3–10s | 反差铺垫 | 观众视角揭示真实身份（观众知、剧中人不知） | 1–2 |
| 10–35s | 冲突升级 | 反派加码羞辱，波及主角在乎的人 | 2–3 |
| 35–70s | 第一次打脸 | 身份/实力小范围兑现，全场震惊 | 2–3 |
| 70–85s | 余波 | 反派靠山现身，威胁升级 | 1 |
| 85–90s | 结尾钩子 | 断在更大危机或身份揭晓前夜 | 1 |

## 四、开头钩子模板（三选一，直接抄）

| 类型 | 公式 | 台词示例 |
| --- | --- | --- |
| 极端羞辱型 | 狠话 + 支票/耳光/下跪 + 众人围观 | 「废物！拿着这五十万，滚出我们林家！」 |
| 身份反差型 | 众人嘲笑 + 一句冷台词 + 特写眼神 | 「世人都笑我是废物赘婿，却不知，我是隐世神医！」 |
| 死亡开局型 | 背叛瞬间 + 坠落/濒死 + 恨意特写 | 「我信错两人，落得身死道消！」 |

## 五、结尾钩子模板（三选一）

| 类型 | 公式 | 台词示例 |
| --- | --- | --- |
| 危机降临型 | 刚解决小麻烦 → 更大麻烦电话/人物登场 | 「什么?!公司资金链断裂?!」 |
| 摊牌前夜型 | 反派扬手/扇耳光定格 + 主角眼神一凛 | 「敢欺我者，今日，全部清算！」 |
| 新人物出场型 | 对峙中 → 更强人物推门而入 | 「我看谁敢动我的人。」 |

## 六、人设卡模板（填空即用，字段对齐 MD-022）

| 字段 | 填写规则 | 示例 |
| --- | --- | --- |
| 姓名 | 事实类，客户未提供则「未指定」 | 叶辰 |
| 表层身份 | 全剧人知的身份 | 林家上门赘婿 |
| 真实身份 | 第 1 集只给观众看 | 北境战神 / 顶尖神医 |
| 外观锁定串 | 发型发色+瞳色+服装配色+稳定识别特征，**与场景无关** | 板寸黑发、剑眉星目、黑西装白衬衫、左腕旧疤 |
| 标志物 | 必填，观众认人核心 | 金丝眼镜 / 左腕红绳 |
| 性格关键词 | ≤ 3 个 | 隐忍、冷峻、护短 |
| 声线 | 设计类，系统可提议 | 低沉偏冷 |

反派/势利亲戚同表填写，**反派必须有具体恶行台词**（嫌贫爱富、势利逼婚），忌纯脸谱。

## 七、台词与命名规范

| 规则 | 要求 |
| --- | --- |
| 单句长度 | ≤ 15 字，重音字在脚本中标注 |
| 语速 | 台词字数 ÷ 该镜秒数 ≤ 9（设计口径 4–6 字/秒） |
| 打脸台词 | 短、冷、留白；不解释长篇背景 |
| 事实命名 | 人名/机构名/数值未提供一律「未指定」，不得编造 |

## 八、审核红线

| # | 红线 | 处置 |
| --- | --- | --- |
| 1 | 不过度低俗、暴力 | 打脸用气场/身份/实力碾压，不用血腥 |
| 2 | 不宣扬拜金主义正面化 | 打脸对象是「势利行为」而非财富本身 |
| 3 | 涉医涉法表述 | 神医设定避免真实疾病诊疗承诺 |
| 4 | 未成年人相关 | 少年逆袭线避开校园霸凌细节渲染 |

## 九、AI 出图适配要点

- 高频场景（酒会、写字楼、豪车、雨夜街头）出图稳定，优先把冲突安排在这类场景。
- 「众人围观」镜头人物多、崩脸率高 → 拆为 2–3 镜近景轮切，或用背影/虚化处理群演。
- 打脸瞬间的「全场震惊」用**特写轮切**（反派瞳孔、众人张嘴、主角冷眼），不要一张大合影。
