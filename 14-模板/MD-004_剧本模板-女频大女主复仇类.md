# MD-004 剧本模板·女频大女主复仇类

> 覆盖子题材：**真假千金、离婚逆袭、年代重生种田、落魄千金复仇、宝妈逆袭**。
> 市面验证：女频常青爆款——「女主清醒不恋爱脑、Girls help girls、恶人得到惩罚」，情绪宣泄强、追更率高；年代重生种田为当前最稳大盘。

---

## 一、题材画像

| 项 | 取值 |
| --- | --- |
| 受众 | 女性为主（25–45 岁），付费意愿强 |
| 单集时长 | 90–120 秒（9:16 竖屏） |
| 推荐画风 | 精致女频漫剧（豪门线）/ 复古国漫（年代线）/ 古风原画（古言线） |
| 核心情绪 | 委屈压抑 → 清醒觉醒 → 步步反杀 → 大仇得报 |
| 女主铁律 | **不恋爱脑**——主线是搞钱/搞事业/拿回身份，感情线只能是配菜 |

## 二、各子题材叙事公式

| 子题材 | 公式 | 关键节点 |
| --- | --- | --- |
| 真假千金 | 识别假货 → 亲子鉴定/身世亮出 → 打脸偏心父母 → 手撕假千金 → 拿回一切 | 第 1 集「双画面对比」开场（门内生日宴 vs 门外淋雨） |
| 离婚逆袭 | 背叛实锤 → 净身出户 → 创业/翻身 → 前夫追悔莫及 | 离婚必须女主主动提，姿态清醒 |
| 年代重生种田 | 临死看清极品 → 重生回关键节点 → 分家/护母 → 开荒搞钱 | 重生转场要给「年轻的双手」特写 |
| 落魄千金复仇 | 家道中落 → 隐忍蛰伏 → 步步为营 → 拿回家族公司 | 前期压抑不过 2 集，第 3 集必须第一次反击 |
| 宝妈逆袭 | 牺牲被嫌弃 → 果断离婚 → 事业崛起 → 双向尊重 | 忌「为了孩子忍」旧套路，走清醒线 |

## 三、单集节拍表（90 秒）

| 时间段 | 节拍 | 内容要求 | 镜数 |
| --- | --- | --- | --- |
| 0–3s | 黄金钩子 | 委屈顶点或觉醒宣言，冷暖对比画面 | 1 |
| 3–10s | 觉醒/身份亮出 | 台词必须是「宣言式」，非解释式 | 1–2 |
| 10–40s | 正面交锋 | 与反派同场对峙，女主气场压过 | 2–3 |
| 40–70s | 第一次反击兑现 | 证据/行动落地，反派受挫 | 2 |
| 70–90s | 恶人反扑钩子 | 反派靠山/新阴谋登场，定格 | 1 |

## 四、开头钩子模板

| 类型 | 公式 | 台词示例 |
| --- | --- | --- |

## 六、人设卡模板

| 字段 | 女主 | 反派（假千金/极品亲戚/出轨夫） |
| --- | --- | --- |
| 外观锁定串 | 固有特征+标志物（眼角泪痣、白衬衫黑裙） | 与女主形成**色彩对位**（女主冷色、反派暖艳） |
| 性格关键词 | 清醒、隐忍、果决 | 虚伪、贪婪、色厉内荏 |
| 核心动机 | 拿回身份/事业/尊严 | 侵占身份/财产/地位 |
| 台词基调 | 短句、冷、留白 | 尖酸、双标、被拆穿时失态 |

## 七、审核红线

| # | 红线 | 处置 |
| --- | --- | --- |
| 1 | 重男轻女、家暴细节 | 只做冲突引子，**不渲染过程细节** |
| 2 | 婚内出轨实锤画面 | 用证据（聊天记录、照片）呈现，不拍过程 |
| 3 | 「恶有恶报」须走法律/规则途径收口 | 大结局加「证据移交、依法处理」一笔 |
| 4 | 抚养权、赡养纠纷 | 不给出与现行法律冲突的桥段 |

## 八、AI 出图适配要点

- 冷暖对比是本类核心视觉语言（门内暖光/门外雨夜），提示词里**光影必须成对设计**。
- 豪门宴会厅、老式大院、土炕灶台出图稳定；「一家人围堵」群像镜头拆近景轮切。
- 女主「气场压过」的镜头用**慢推 + 低角度仰拍**固定组合。
